为什么做这个？

让 Agent 凭核实过的 API 写游戏，而不是凭训练记忆

🎲 凭记忆写 boardgame.io 的痛点

Agent 凭训练记忆写 boardgame.io 代码会踩一堆坑：使用已过时的 (G, ctx) 双参回调写法、 在 phase 内做回合子流程导致强制结束回合、用 Math.random 破坏确定性随机、 Node ESM 导入路径失败、静态资产 import 在纯 Node 环境报错、unsetStage 调用直接报错。 这些隐蔽问题让 AI 生成的游戏代码看似能跑实则不可用，调试成本极高。

核心原理与步骤

1. 模板路由
简单棋盘游戏（井字棋/五子棋/跳棋类）走 minimal/ 模板；卡牌对战、隐藏手牌、回合内子阶段走 card-game/ 模板。SKILL.md 内建路由逻辑自动选择。
2. API 精要核实
所有签名对照 boardgame.io 0.50.2 源码逐项验证，结合本地仓库源码 + DeepWiki 交叉验证，杜绝凭训练记忆写过时 API。
3. 双环境兼容
静态资产用 new URL(file, import.meta.url).href 写法，打包器与纯 Node 环境通用；测试/脚本走深层导入 boardgame.io/dist/esm/*.js。
4. 经验回灌
类游戏王卡牌游戏、西游斗法等实战踩出的教训，全部沉淀为 SKILL.md 的"UI 可玩性清单"、"game feel 清单"与 references 深度文档。

安装与配置

几步把 skill 装进你的 Agent 工具集

1. 克隆 skill 仓库

获取 skill 文件：

git clone https://github.com/liangdabiao/boardgame-io-skill.git
cd boardgame-io-skill
2. 放入 Agent skills 目录

将整个目录放入 Codex/Workbuddy/ZCode 等 Agent 的 skills 加载路径：

.agents/skills/boardgame-io-skill/
├── SKILL.md
├── references/
└── assets/templates/
3. 自动触发或手动调用

涉及"用 boardgame.io 做个游戏 / 回合制 / 棋牌 / 桌游 / multiplayer / phases / moves"的请求会自动加载；也可手动触发：

/skill boardgame-io <你的需求>
4. 选择模板并生成游戏

让 Agent 基于模板生成游戏代码，并安装 boardgame.io 依赖：

npm install boardgame.io
npm run dev

常见问题

关于 boardgame.io skill 的常见疑问

Q: 这个 skill 和直接读 boardgame.io 官方文档有什么区别？
A: skill 把文档核实过的 API、踩过的坑、项目模板和工作流封装好，Agent 加载后直接产出可用代码，避免凭训练记忆写过时的 (G, ctx) 双参写法或调用已移除的 unsetStage。
Q: 支持哪些类型的游戏？
A: 覆盖棋盘/卡牌/骰子类回合制游戏、隐藏信息游戏、本地热座与 SocketIO 联机多人模式。实时游戏不在擅长范围。
Q: 需要联网吗？
A: 加载 skill 后生成代码不需要联网；但安装 boardgame.io npm 依赖、联机模式运行时需要网络。
Q: 如何升级到新版本 boardgame.io？
A: 重点复查三处：回调签名、Node exports 映射（若官方加上可简化深层导入）、events API 列表。详见仓库维护指南。
Q: 模板可以独立使用吗？
A: 可以。minimal 与 card-game 两个模板都已在干净目录通过安装、测试、构建验证，可直接克隆作为项目起点。
