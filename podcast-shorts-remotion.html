安装与配置

快速生成你的第一个播客短视频

前置条件

Python 3.10+、Node.js 16+、FFmpeg、Whisper（base模型本地运行）。

1. 创建项目
python3 scripts/scaffold_podcast_shorts_project.py \
  --project-dir "video/新项目/hf" \
  --audio "播客.mp3" --script "播客脚本.md" --title "视频标题"
2. 预览渲染
TEMP=D:/tmp npm run render:preview
# 输出：out/preview-low.mp4（540×960）
3. 最终渲染
npm run render
# 输出：1080×1920 竖屏最终视频

常见问题

Q: Whisper需要联网吗？
A: 不需要。使用Whisper base模型本地运行，无需API Key，无需联网即可转录。
Q: 字幕宽度规则是什么？
A: 中文字符视觉宽度=1，ASCII字符=0.6，单行总宽度≤20，自动换行保证字幕美观可读。
Q: 为什么需要预渲染？
A: 540×960预渲染约比1080×1920最终渲染快4倍，可作为最终剪辑的参考，确认无误后再做最终渲染。
