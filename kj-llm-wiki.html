安装与配置

快速搭建本地Wiki文档环境

1. 克隆项目

获取Wiki项目：

git clone https://github.com/liangdabiao/kj-llm-wiki.git
cd kj-llm-wiki
2. 安装依赖

安装Quartz和项目依赖：

npm install
# 安装Python依赖（如需要）
pip install -r requirements.txt
3. 本地预览

启动本地Wiki预览：

npx quartz build --serve
# 访问 http://localhost:8080
4. 编写与发布

编辑content目录下的Markdown文件，构建并发布：

# 构建静态网站
npx quartz build
# 部署到GitHub Pages
npx quartz build --publish

常见问题

关于跨境电商AI Wiki的常见疑问

Q: 什么是LLM-Wiki方法？
A: LLM-Wiki是Karpathy提出的一种利用大语言模型辅助知识管理的方法。通过LLM自动整理、摘要和关联知识内容，提高文档编写的效率和质量。
Q: 文档内容是否适合新手？
A: 文档从基础概念讲起，逐步深入到实战应用。无论是跨境电商新手还是AI技术新手，都能找到适合自己的内容。
Q: 代码示例可以直接使用吗？
A: 代码示例都经过实际测试，可以根据自己的需求和环境进行适当的参数调整后直接使用。
Q: 如何贡献内容？
A: 欢迎通过GitHub Pull Request贡献内容。可以提交新的文档、修正现有内容或添加实战案例。
