为什么做这个？

电商最核心的资产是大量经过市场验证的爆款图

📸 传统宣传图制作的痛点

跨境电商场景中，商家每出一款新品都需要制作宣传图（模特穿着商品的照片）。传统方式需要请模特、搭场景、拍摄修图，成本高、周期长。模特表现力、场景构图、光影质感，都是花钱试出来的。与其每次从零写 prompt，不如直接从历史爆款中检索最相似的视觉特征，让 AI 继承"爆款基因"。这正是 Milvus 混合检索发挥作用的地方。

核心功能

从爆款检索到AI生图的全链路自动化

🔍

以图搜爆款

将新品平铺图与历史爆款库做混合检索（视觉相似 + 关键词匹配 + 销量过滤），找到风格最接近的爆款，继承"爆款基因"

🧠

AI风格分析

将爆款参考图发给大语言模型 Qwen 3.5，自动分析场景、灯光、姿势、氛围，生成风格描述 prompt

🎨

AI生成宣传图

将新品图 + 爆款参考 + 风格描述一起发给图像生成模型（Gemini / GPT Image），输出专业宣传图

🔗

混合检索引擎

Dense向量（图片Embedding视觉相似）+ Sparse向量（TF-IDF关键词匹配）+ 标量筛选（品类销量过滤），三路融合 + RRF重排序

🗄️

Milvus向量数据库

基于Milvus构建商品向量库，支持2048维Dense向量 + TF-IDF Sparse向量，混合检索精度远超单一方式

⚡

多模型灵活切换

支持 Nano Banana 2 (Gemini)、GPT-5.4 Image 2、GPT-5 Image Pro、GPT-5 Image Mini，通过 --model 参数一键切换

📐

多比例多分辨率

支持 1:1、3:4、4:1、9:16 等多种宽高比，分辨率支持 512px 到 4K，适配不同平台素材需求

☁️

技术架构详解

1. 向量编码
使用 llama-nemotron-embed-vl-1b-v2 模型，将商品图片编码为 2048 维 Dense 向量，文本描述经 TF-IDF 生成 Sparse 向量
2. Milvus 混合检索
Dense（视觉相似）+ Sparse（关键词匹配）+ Scalar（品类 + 销量过滤），通过 RRF（Reciprocal Rank Fusion）重排序，检索精度远超单一方式
3. Qwen 3.5 风格分析
调用多模态大语言模型 Qwen 3.5，同时理解图片和文本，自动分析爆款参考图的场景、灯光、姿势、氛围，输出风格描述 prompt
4. AI 宣传图生成
将新品图 + 爆款参考图 + 风格描述 prompt 发送给 Gemini 或 GPT Image 模型，支持多参考图融合、多比例、高分辨率输出

为什么用混合检索？

单一检索方式有盲区，三者结合精度远超单一方式

检索方式 擅长 弱点
Dense 向量（图片 Embedding） 视觉相似度（颜色、款式、风格） 不擅长精确关键词匹配
Sparse 向量（TF-IDF） 关键词语义（"floral"、"midi"、"chiffon"） 不理解视觉特征
标量筛选 品类过滤、销量排序 无法理解语义
混合检索 + RRF ✅ 三者优势互补 ✅ 无明显盲区

安装与配置

简单几步，启动电商AI生图流水线

1. 环境准备

Python 3.10+、Zilliz Cloud 账号（免费 tier 即可）、OpenRouter 账号和 API Key

2. 克隆项目并安装依赖

获取项目代码并安装依赖：

git clone https://github.com/liangdabiao/Fashion-AI.git
cd Fashion-AI
pip install -r requirements.txt
3. 配置 .env

填写 API Key 配置：

OPENROUTER_API_KEY=sk-or-v1-xxxxx
MILVUS_HOST=https://xxx.gcp.zillizcloud.com
MILVUS_TOKEN=your-zilliz-api-key
COLLECTION_NAME=fashion_products

OPENROUTER_API_KEY 在 openrouter.ai/keys 获取；MILVUS_HOST / MILVUS_TOKEN 在 Zilliz Cloud 控制台创建集群后获取

4. 准备数据

将商品图片放入 images/ 目录，新品平铺图放入 new_products/ 目录。编辑 products.csv 和 new_products.csv 填入真实商品信息。首次运行 setup 时程序会自动创建 CSV 模板和占位图。

5. 运行流水线

三步完成：

# Step 1: 建库入库（首次运行或数据更新时执行）
python main.py setup

# Step 2: 测试检索（可选，验证混合检索是否正常）
python main.py search --new-id NEW001

# Step 3: 完整流水线（检索 → 风格分析 → 生图）
python main.py generate --new-id NEW001

# 使用 GPT-5.4 Image 2 生图
python main.py generate --new-id NEW001 --model gpt-image

# 使用 GPT-5 Image Pro 生图
python main.py generate --new-id NEW001 --model gpt-image-pro

CLI 参数说明

setup - 初始化数据

python main.py setup

初始化数据，生成向量，创建 Milvus Collection 并入库。重复运行会重建 Collection。

search - 为新品检索相似爆款

python main.py search [OPTIONS]
--new-id 指定新品 ID，如 --new-id NEW001（默认：全部）
--top-k 返回结果数量（默认：3）
--sales-threshold 最低销量过滤门槛（默认：1500）

generate - 完整流水线

python main.py generate [OPTIONS]
--new-id 指定处理某个新品（默认：全部）
--top-k 参考爆款数量（默认：3）
--sales-threshold 最低销量过滤门槛（默认：1500）
--aspect-ratio 生成图宽高比，支持 1:1, 3:4, 4:1, 9:16 等（默认：3:4）
--image-size 生成图分辨率：512px, 1K, 2K, 4K（默认：2K）
--model 生图模型：nano-banana, gpt-image, gpt-image-pro, gpt-image-mini（默认：nano-banana）

常见问题

关于电商AI生图爆款流水线的常见疑问

Q: 需要本地 GPU 吗？
A: 不需要。所有模型通过 OpenRouter API 调用，向量数据库使用 Zilliz Cloud 免费tier，完全零硬件成本。
Q: 支持哪些生图模型？
A: 支持 Nano Banana 2 (Gemini 3.1 Flash)、GPT-5.4 Image 2、GPT-5 Image Pro、GPT-5 Image Mini，通过 --model 参数一键切换。
Q: 什么是混合检索？
A: 混合检索结合了 Dense 向量（视觉相似度）、Sparse 向量（关键词匹配）和标量筛选（品类销量过滤），通过 RRF 融合排序，精度远超任何单一检索方式。
Q: 如何添加自己的商品数据？
A: 将商品图片放入 images/ 目录，编辑 products.csv 填入商品信息（品类、颜色、风格、销量、描述等），运行 python main.py setup 重建向量库即可。
Q: 生成的宣传图支持哪些比例和分辨率？
A: 支持 1:1、3:4、4:1、9:16 等多种宽高比，通过 --aspect-ratio 参数指定。分辨率支持 512px 到 4K，通过 --image-size 参数控制。Gemini 系列还支持 8:1/1:8 超宽超高比例。
Q: 已知限制有哪些？
A: 占位图无法用于实际检索和生图，必须替换为真实商品照片；图片分辨率影响 Embedding 质量，建议商品图不低于 800x800；Nano Banana 2 在服装与人体融合上偶尔不自然，可通过分步生图或使用 Pro 版本改善；Milvus Lite 不支持 Windows，本项目使用 Zilliz Cloud 替代。
