为什么做这个小程序？

随时随地创作拼豆像素画

🎨 移动端拼豆创作的需求

拼豆（Perler Beads）是一种深受欢迎的手工创作活动，但传统的创作方式需要使用电脑软件设计图纸。 本项目将拼豆像素画创作搬到微信小程序上，让你随时随地都能进行创作。基于Taro+Vue3跨平台框架开发， 二开自noir017/perlerBeadsApplet，增加了更多实用功能。

核心功能

8大核心功能，移动端拼豆创作全流程支持

🖌️

像素画编辑器

专业级像素画编辑器，支持逐像素绘制、颜色选择、橡皮擦、填充等操作，流畅的触摸操作体验

📁

作品管理

完整的作品管理系统，保存、浏览、编辑、删除作品，支持作品缩略图预览和快速加载

🖼️

图片导入生成

支持从手机相册导入图片，自动转换为拼豆像素画，智能颜色匹配和尺寸适配

📄

图纸导出

一键导出高清拼豆图纸，包含色号标注和用量统计，方便实际拼搭参考

📱

微信小程序

原生微信小程序体验，无需安装独立App，打开微信即可使用，方便分享给好友

🎨

拼豆色号匹配

内置完整拼豆色号库，精确匹配每个像素对应的拼豆颜色，支持多种拼豆品牌色号

📐

多种尺寸支持

支持多种拼豆底板尺寸，从小型挂件到大型壁画，满足不同规模的创作需求

🔗

作品分享

一键分享作品到微信好友或朋友圈，展示你的拼豆创作成果，获取朋友点赞

创作流程详解

1. 启动与选择
打开微信小程序，选择新建空白画布或从相册导入图片作为创作基础
2. 编辑创作
使用编辑器工具进行像素画绘制，支持颜色选择、填充、橡皮擦等多种操作
3. 色号匹配
自动将每个像素匹配到对应的拼豆色号，显示用量统计和颜色列表
4. 导出与分享
导出高清图纸用于拼搭，或直接分享作品到微信好友展示成果

安装与配置

开发者快速上手指南

1. 克隆项目

获取项目代码：

git clone https://github.com/liangdabiao/perlerBeadsApplet.git
cd perlerBeadsApplet
2. 安装依赖

安装项目依赖：

npm install
# 或使用 yarn
yarn install
3. 编译项目

编译微信小程序版本：

npm run build:weapp
# 或开发模式
npm run dev:weapp
4. 微信开发者工具预览

使用微信开发者工具打开 dist 目录即可预览和调试。

常见问题

关于拼豆像素画小程序的常见疑问

Q: 普通用户如何使用？
A: 在微信中搜索小程序名称即可直接使用，无需下载安装独立App，打开即用。
Q: 支持哪些拼豆品牌？
A: 内置多种拼豆品牌色号库，包括常见品牌如MARD、COCO等，也支持自定义色号。
Q: 导入图片的效果如何？
A: 图片导入后自动进行像素化和颜色匹配处理，支持手动微调，确保转换为可实际拼搭的图纸。
Q: 与原版noir017项目有什么区别？
A: 在原版基础上增加了更多编辑工具、图片导入优化、图纸导出、作品分享等功能，提升了用户体验和实用性。
