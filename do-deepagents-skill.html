为什么需要 DeepAgents？

单一提示词撑不住复杂任务

🤔 传统AI Agent的痛点

真实业务往往是：多步推理、多工具组合、长会话、还要记用户偏好和历史决策。把一切都塞进一个 Chat 里，容易出现指令被淹没、行为漂移、失败不可定位。这就是为什么像 Claude Code/Codex/Workbuddy 、Deep Research、Manus 这样的应用能够脱颖而出。

快速代码示例

from deepagents import create_deep_agent

def get_weather(city: str) -> str:
    """Get weather for a given city."""
    return f"It's always sunny in {city}!"

agent = create_deep_agent(
    model="anthropic:claude-sonnet-4-6",
    tools=[get_weather],
    system_prompt="You are a helpful assistant",
)

result = agent.invoke(
    {"messages": [{"role": "user", "content": "What is the weather in SF?"}]}
)
print(result["messages"][-1].content)

常见问题

关于 DeepAgents Framework Skill 的常见疑问

Q: DeepAgents 和 LangGraph 有什么区别？
A: DeepAgents 是构建在 LangChain + LangGraph 之上的独立库，提供了有主见的默认配置，让开发者无需从零搭建复杂的 Agent 架构。
Q: 这个 Skill 如何使用？
A: 将 SKILL.md 和 references 目录放入 Claude Code/Codex/Workbuddy 的 .claude/skills/ 目录，Claude Code/Codex/Workbuddy 就能自动学习 DeepAgents 框架知识，辅助你开发。
Q: 支持哪些存储后端？
A: 支持 StateBackend、FilesystemBackend、StoreBackend、Sandbox 等多种后端，可根据部署需求灵活选择。
