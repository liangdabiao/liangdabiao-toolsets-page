核心流程详解

1. 内容输入
支持多种输入方式：直接输入文本、发送微信公众号文章链接、上传doc文档。AI自动识别内容类型并进行解析。
2. AI智能处理
AI自动下载文章内容、图片素材，分析核心观点，设计对话文案，规划视频页面排版和信息展示节奏。
3. 语音合成
基于MiniMax TTS生成流畅的中文语音旁白，语音自然度接近真人水平，成本极低(10元即可大量使用)。
4. 视频渲染输出
使用HyperFrames引擎渲染最终视频，支持信息流快消风格，输出横版或竖版视频，可直接上传至各短视频平台。

安装与配置

简单几步，开始AI视频创作之旅

1. 安装 HyperFrames

首先安装 HyperFrames 基础环境：

参考安装指南：HyperFrames 安装教程

2. 克隆项目并添加 references

获取 HyperFrames-fix 项目代码：

git clone https://github.com/liangdabiao/hyperframes-fix.git

将项目中的 references 文件添加到你安装的 HyperFrames skill 目录中，然后告知AI情况，让AI补充进 HyperFrames skill。

3. 配置环境变量

编辑 .env 文件，配置必要的 API Key：

# .env 配置
MINIMAX_KEY=你的MiniMax_API_Key
PEXELS_API_KEYS=你的Pexels_API_Key
4. 开始制作视频

配置完成后，直接发送视频制作需求：

视频制作需求：
请阅读根目录的 #播客脚本.md，目的是基于内容总结核心观点，
生成信息图，利用 hyperframes skill 生成流畅的视频。
要求：
1. 带语音的视频
2. 页面大概20个左右，内容充实
3. 手机尺寸版本
4. 信息流快消风格
