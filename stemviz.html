安装与使用

快速开始

1. 克隆项目
git clone https://github.com/liangdabiao/STEMViz.git
2. 安装依赖
pip install -r requirements.txt
# 另需安装 FFmpeg 与 LaTeX（MiKTeX）
3. 配置密钥
cp .env.example .env
# 填入豆包火山方舟 API Key 与 TTS API Key
4. 启动使用
python app.py  # 浏览器打开 http://127.0.0.1:7860

常见问题

关于 STEM 概念动画生成器 的常见疑问

Q: 生成一条视频要多久？
A: 约 10-30 分钟，取决于概念复杂度与场景数量。
Q: 需要哪些 API？
A: 豆包火山方舟 API Key（LLM + 多模态理解）和豆包 TTS API Key（语音合成）。
Q: 数学公式渲染异常怎么办？
A: 确保 MiKTeX 已安装并加入 PATH；不装 LaTeX 会降级为纯文本渲染，效果较差。
