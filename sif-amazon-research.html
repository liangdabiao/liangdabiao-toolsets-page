功能详解

每个模块的核心能力

📈

流量分析

深入分析 ASIN 的流量趋势、渠道构成和变体分布。了解流量来源，识别增长机会，优化运营策略。

🔍

关键词研究

反查 ASIN 的关键词来源，分析关键词健康度和排名演化，发现市场机会词和竞争薄弱点。

📣

广告分析

分析广告活动结构、关键词表现和 CPC 评估。优化广告投放策略，提高广告效率。

🎯

竞品分析

多维度评估竞品强度，识别攻击点和弱点，制定竞争策略和差异化方向。

⚕️

智能诊断

AI 驱动的流量异常根因分析，自动定位问题根源并提供改进建议。

💡

机会挖掘

批量评估关键词机会，分析市场可行性，识别价格带机会和进入门槛。

RESTful API 文档

API 基础路径：http://localhost:3000/api

接口 方法 描述
/api/health GET 健康检查，返回系统状态
/api/dashboard/summary GET 获取仪表盘摘要数据
/api/research/traffic POST 流量分析报告
/api/research/keywords POST 关键词分析报告
/api/research/ads POST 广告分析报告
/api/research/diagnose POST AI 智能流量诊断
/api/research/competitor POST 竞品深度分析
/api/research/keyword-opportunity POST 关键词机会评估
/api/research/market-validation POST 市场可行性验证
/api/research/full POST 全维度综合调研
/api/reports GET 获取报告列表
/api/reports/{reportId} GET / DELETE 查看或删除单个报告

📡 API 使用示例

使用 curl 测试 API：

# 流量分析
curl -X POST http://localhost:3000/api/research/traffic \
  -H "Content-Type: application/json" \
  -d '{"asin":"B0CLPGQWNB","country":"US"}'

# 关键词分析
curl -X POST http://localhost:3000/api/research/keywords \
  -H "Content-Type: application/json" \
  -d '{"asin":"B0CLPGQWNB","country":"US","topN":30}'

快速开始

简单几步，启动 Amazon 卖家智能调研平台

前置条件

Node.js >= 16.0.0、有效的 Sif MCP secret-key（已内置在 config.json 中）、现代浏览器

一键启动（推荐 Windows 用户）
start.bat

启动后自动在浏览器访问 http://localhost:3000

命令行启动
cd sif-amazon-research
npm install
npm start
示例脚本
# 运行示例
node examples/demo.js help    # 查看帮助
node examples/demo.js 1       # 流量报告
node examples/demo.js 2       # 关键词审计
node examples/demo.js 3       # 广告报告
node examples/demo.js 4       # 流量诊断
node examples/demo.js 5       # 竞品分析
node examples/demo.js all     # 运行所有示例
