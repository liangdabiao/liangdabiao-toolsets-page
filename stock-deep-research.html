🎯

需求澄清先行

先问清投资风格、持有周期、关注点和风险偏好，再生成研究计划

🔬

8 阶段尽调

公司事实、行业周期、业务拆解、财务质量、股权治理、市场分歧、估值护城河 + 综合报告

👥

多研究员并行

多个 AI 研究员分头干活，比串行快得多

⚖️

强制交叉验证

经营现金流对账净利润、同行全面对标，必列 3-5 个看空风险

📚

A-E 来源评级

每个声明标来源并评级（A 年报/E 论坛），附幻觉检测

🚦

信号灯评级

报告末尾给三绿/三黄/两红信号灯，但明确不预测股价、不荐股

安装与使用

快速开始

1. 安装技能到 AI 助手
git clone https://github.com/liangdabiao/stock-deep-research-skill.git
# 放入 ~/.workbuddy/skills/ 或 ~/.claude/skills/

对 AI 说：帮我研究一下贵州茅台 600519 值不值得投资

常见问题

关于 股票尽调一体化引擎 的常见疑问

Q: 和站上的股票深度研究代理什么关系？
A: 同源方法论：那个是 Claude Code 版项目，这个是技能版，装在 agent 里随取随用。
Q: 能研究非股票主题吗？
A: 可以，走通用研究流程产出带引用的行业报告，也能检查已有报告的引用质量。
