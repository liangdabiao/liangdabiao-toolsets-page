👥 人群场景

  • 使用场景：儿童玩乐、成人收藏、节日礼物、汽车爱好者
  • 购买动机：价格优势、设计喜欢、替代乐高、性价比考虑
  • 用户需求：功能需求、情感需求、社交需求

🎯 功能价值

  • 产品优点：零件齐全、组装容易、设计精美、功能多样
  • 产品缺点：零件缺失、零件松动、组装困难、指示不明
  • 用户建议：优化指示、提升质量、改进包装
  • 设计外观：整体造型、内部细节、颜色搭配

🛡️ 保障价值

  • 物流配送：配送速度、包装完整性
  • 售后服务：补发零件、退款处理、客服响应
  • 售前服务：信息咨询、产品介绍、购买指导
  • 品质保证：质量承诺、售后支持

✨ 体验价值

  • 推荐意愿：是否愿意推荐、推荐原因分析
  • 品牌印象：质量认知、价格感知、品牌信任度
  • 感官感受：外观美感、零件质感、使用体验
  • 价格感知：价格合理性、性价比评估

环境准备

# 1. 安装Python 3.10+ # 2. 克隆项目 git clone https://github.com/liangdabiao/easy-amazon-voc cd easy-amazon-voc # 3. 安装依赖 pip install -r requirements.txt

配置大模型API

# 在 function.py 中配置API密钥 import openai openai.api_key = "your api key" # 支持兼容OpenAI接口的大模型 # 目前使用字节豆包，也可配置其他模型 model="doubao-1.5-pro-32k-250115"

💡 支持所有兼容OpenAI API的大模型服务

运行系统

# 启动Flask应用 python app.py # 访问 http://localhost:5000 开始使用
