搜索谁都会，搜出结构化洞察是另一回事

普通搜索引擎返回的是链接列表，做调研还得自己读、自己筛、自己组织。这套平台把 Exa 的高质量检索能力接进 Claude Agent SDK：企业调研、外贸市场分析、竞品研究都是内置技能，对话即可完成从搜索到结构化报告的全程。

安装与使用

快速开始

1. 克隆项目
git clone https://github.com/liangdabiao/claudesdk-exa-chat.git
2. 安装依赖
npm install
3. 配置密钥
配置 Claude API Key 与 Exa API Key
4. 启动服务
npm start  # 浏览器打开后对话提问
