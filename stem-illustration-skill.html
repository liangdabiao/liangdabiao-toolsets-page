为什么需要STEM专用插图Skill？

通用AI画不好科研示意图

通用AI画科研图常出错

通用AI（DALL-E、Midjourney）画科研示意图常出错：蛋白质结构不合理、化学键角度错误、电路图不严谨。本Skill内置24个STEM场景模板、6学科专属知识、4种风格变体（学术/教科书/信息图/3D渲染），并设置学术诚信守卫，拦截伪造实验数据，确保科研插画准确专业。

安装与配置

一行命令生成专业STEM插图

前置条件

Python 3.8+、OpenAI兼容API Key或apimart.ai API Key、Claude Code/Codex/Workbuddy / Codex Agent。

1. 配置环境
cp .env.example .env
# 填写 IMG_BASE_URL / IMG_MODEL / IMG_API_KEY
2. 编写提示
# 在prompt.txt中描述需求
echo "绘制大肠杆菌乳糖操纵子信号通路，学术风格" > ./prompt.txt
3. 生成图像
python scripts/generate_image.py \
  --prompt-file ./prompt.txt \
  --size 3:4 --resolution 2k

常见问题

Q: 学术诚信守卫如何工作？
A: 当请求涉及伪造实验数据、虚构研究结果、PS篡改真实实验图时，守卫会主动拦截并拒绝生成，避免学术不端。
Q: 4种风格变体有什么区别？
A: 学术风格（论文配图）、教科书风格（教学插画）、信息图风格（科普传播）、3D渲染风格（视觉冲击）。
Q: 10条STEM提示铁律是什么？
A: 涵盖十六进制颜色规范、字体选择、术语准确性、比例尺、坐标系、标注规范等10条专业制图规则。
