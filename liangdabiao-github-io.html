三步学习路径

📚 学习路径

第一步：入门先行 从四本入门书里挑：想懂概念看《真·AI Agent小蓝书》；想零代码出活看阿里云百炼；想从代码开始看LangGraph；想把经验沉淀成可复用技能看Agent Skills。
第二步：进阶深入 挑一个Agent框架深入学习（Claude Agent SDK / OpenAI Agents SDK / Flue / Vercel Eve / DeepAgents / DeerFlow），掌握框架核心能力。
第三步：托管上线 学习Cloudflare Agents / EdgeOne Makers部署指南，把Agent部署到边缘/云平台，不用管运维，实现真正的生产上线。
