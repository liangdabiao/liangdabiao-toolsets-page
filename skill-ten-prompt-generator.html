安装使用

简单3步，开始使用AI提示词工程系统

前置要求

  • 安装 Claude Code
  • 确保版本支持 Agent Skills (1.0+)
  • 将项目克隆到本地

安装步骤

# 克隆项目
git clone https://github.com/liangdabiao/skill-ten-prompt-generator.git
cd skill-ten-prompt-generator

# Skills 会自动被 Claude Code 发现
# 确认安装：在 Claude Code 中询问 "What Skills are available?"

使用方法

直接在 Claude Code 中用自然语言描述你的需求，系统会自动识别场景并调用对应的 Skill。例如：

  • "帮我生成一个 Flux 模型的图像提示词"
  • "写一个 Python 数据分析的 .cursorrules"
  • "把这段AI生成的文字改得更自然"
