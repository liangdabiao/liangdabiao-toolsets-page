使用流程详解

1. 选择合适的Skill
根据数据来源和需求，选择对应的Skill工具，如网页抓取、文档提取或API调用
2. 配置获取参数
在Claude Code中用自然语言描述数据获取需求，AI自动配置参数并执行
3. 数据获取与清洗
自动获取数据并进行清洗、去重、格式转换等处理，确保数据质量
4. 结构化输出
输出结构化的数据结果，支持JSON、CSV、数据库等多种格式和存储方式

安装与配置

快速集成到Claude Code开发环境

1. 克隆项目

获取Skills合集：

git clone https://github.com/liangdabiao/fetch-everything.git
cd fetch-everything
2. 安装到Claude Code

将Skills安装到Claude Code环境：

# 复制所有Skills到Claude Code目录
cp -r skills/ ~/.claude/skills/
3. 安装Python依赖

安装所需的Python库：

pip install -r requirements.txt
4. 开始使用

在Claude Code中使用Skills：

# 在Claude Code中调用Skill
claude "抓取这个网页的内容: https://example.com"
claude "提取这个PDF文档中的表格数据"

常见问题

关于Fetch Everything Skills工具箱的常见疑问

Q: 这些Skills是否合法使用？
A: 工具本身是合法的，但使用时需遵守目标网站的robots.txt和服务条款。建议仅用于合法的数据获取场景，如公开数据分析、自有平台管理等。
Q: 支持哪些中文平台？
A: 经过特别优化的中文平台包括淘宝、京东、拼多多、微博、知乎、豆瓣、B站等主流中文网站。持续增加更多平台支持。
Q: 可以单独使用某个Skill吗？
A: 可以。每个Skill都是独立的，可以单独安装和使用。根据你的需求选择需要的Skill即可。
Q: 支持openclaw吗？
A: 是的，Skills同时兼容Claude Code和openclaw环境。安装方式基本相同。
