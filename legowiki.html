核心工作流详解

1. 知识库初始化

2. 内容创建与编辑

3. AI智能整理
AI自动分析内容结构，生成摘要和标签，推荐相关知识条目
4. 知识关联与检索
通过双向链接和标签系统建立知识网络，支持全文搜索快速定位

安装与配置

简单几步，开始构建你的知识库

1. 克隆项目

获取项目代码：

git clone https://github.com/liangdabiao/legowiki.git
cd legowiki
2. 安装依赖

安装Python依赖：

pip install -r requirements.txt
3. 初始化知识库

运行初始化命令：

python init.py
4. 启动服务

启动本地知识库服务：

python run.py
# 访问 http://localhost:8080

常见问题

关于 Lego Wiki 的常见疑问

Q: Lego Wiki 适合什么场景使用？
A: Lego Wiki 适合个人知识管理、团队文档协作、技术文档整理、学习笔记管理等多种场景。无论是学生、开发者还是知识工作者，都可以通过它构建自己的知识体系。
Q: AI辅助功能需要联网吗？
A: 部分AI功能需要联网调用API，但也支持本地模型运行。具体取决于你的配置和使用的AI模型。
Q: 支持哪些内容格式？
A: 主要支持Markdown格式编写，同时兼容HTML、纯文本等格式。支持导出为PDF、HTML等多种格式。
Q: 数据存储在哪里？
A: 默认数据存储在本地文件系统中，完全掌控数据安全。也支持配置外部数据库存储。
