使用方法

三种方式，灵活选择

💡 零门槛使用

作为 Claude Code Agent Skill，您可以直接通过对话调用API，无需编写任何代码。只需描述您的需求，AI会自动搜索合适的API并执行调用。

方式一：Claude Code 对话（推荐）

# 直接通过对话调用
你: "调研各外国平台讨论 deepseek 的帖子"

# Claude 自动执行以下操作：
# 1. 搜索相关的 TikHub API
# 2. 选择合适的 API 端点
# 3. 调用 API 获取数据
# 4. 整理并返回结果

Claude: [返回各平台关于 deepseek 的讨论数据]

方式二：命令行API搜索

# 搜索关键词
python .claude/skills/tikhub-api-helper/api_searcher.py "tiktok 用户资料"

# 按标签搜索
python .claude/skills/tikhub-api-helper/api_searcher.py tag:TikTok-Web-API

# 按操作ID搜索
python .claude/skills/tikhub-api-helper/api_searcher.py op:fetch_user_profile

方式三：直接调用API

# 获取用户资料
python .claude/skills/tikhub-api-helper/api_client.py GET /api/v1/tiktok/web/fetch_user_profile "sec_user_id=USER_ID"

# 搜索视频
python .claude/skills/tikhub-api-helper/api_client.py GET /api/v1/tiktok/web/fetch_search_video "keyword=游戏"

# 获取热门话题
python .claude/skills/tikhub-api-helper/api_client.py GET /api/v1/tiktok/web/get_trending_topics

API基本信息

项目 信息
中国用户请求地址 https://api.tikhub.dev (绕过GFW)
国际用户请求地址 https://api.tikhub.io
鉴权方式 Bearer Token
请求限制 每个端点每秒10次请求
端点格式 /api/v1/{platform}/{method}/{action}
