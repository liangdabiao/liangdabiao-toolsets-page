安装与配置

快速集成到Claude Code/Codex/Workbuddy ，开始数据分析

1. 克隆项目

获取Skill代码：

git clone https://github.com/liangdabiao/Amazon-Skills-Liang.git
cd Amazon-Skills-Liang
2. 安装到Claude Code/Codex/Workbuddy

将Skill安装到Claude Code/Codex/Workbuddy 环境中：

# 复制Skill文件到Claude Code/Codex/Workbuddy  Skills目录
cp -r skills/ ~/.claude/skills/
3. 配置API密钥

配置Amazon API相关参数：

# 编辑配置文件，填入你的API密钥
cp config.example.json config.json
# 编辑 config.json 填入相关配置
4. 开始使用

在Claude Code/Codex/Workbuddy 中使用Skill：

# 在Claude Code/Codex/Workbuddy 中直接调用分析命令
claude "分析这个产品的市场竞争力: B0XXXXXXXXX"

常见问题

关于Amazon深度分析Skill的常见疑问

Q: 需要Amazon卖家账号才能使用吗？
A: 部分功能需要Amazon API密钥，建议使用Amazon Seller Central账号获取API权限。基础分析功能无需账号也可使用。
Q: 与原版nexscope-ai/Amazon-Skills有什么区别？
A: 在原版基础上增加了中国卖家专属优化、更深入的数据分析维度、评论情感分析、利润计算等功能，更适合中国卖家的使用场景。
Q: 支持哪些Amazon站点？
A: 目前主要支持Amazon美国站、欧洲站和日本站的分析，后续会逐步增加更多站点的支持。
Q: 数据分析的准确度如何？
A: 数据来源于Amazon官方API和公开数据，结合AI分析能力，提供高准确度的分析结果和商业建议。
