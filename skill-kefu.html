项目背景

打造企业级智能客服，从教程到公开服务的完整实践

为什么做这个项目？

智能客服是企业服务的核心场景，但现有方案往往功能碎片化、难以落地。本系统整合了LangChain/LangGraph教程11个章节的所有核心功能， 从对话记忆、RAG知识库，到情绪识别、意图分类，再到工单系统、多Agent协作，构建了一套完整的、可部署的智能客服解决方案。 系统参考了图解AI系列教程，目标是让SKILL从教程示例变成真正可用的公开服务。

安装与配置

简单几步，搭建完整的智能客服系统

1. 克隆项目

获取项目代码：

git clone https://github.com/liangdabiao/SKILL-kefu.git
cd SKILL-kefu
2. 安装依赖

安装Python依赖包：

pip install -r requirements.txt
3. 配置环境变量

设置LLM API密钥和相关配置：

cp .env.example .env
# 编辑 .env 文件，填入你的 API Key 和配置信息
4. 启动Web界面

使用Streamlit启动可视化界面：

streamlit run web.py
5. 启动API服务

使用FastAPI启动REST API：

uvicorn api:app --host 0.0.0.0 --port 8000 --reload
6. 终端交互模式

直接在命令行中使用：

python main.py

常见问题

关于SKILL智能客服系统的常见疑问

Q: 系统支持哪些LLM模型？
A: 系统基于LangChain构建，支持OpenAI GPT系列、Claude、通义千问等多种LLM模型。只需在配置文件中修改模型参数即可切换。
Q: 如何添加自定义知识库？
A: 将知识文档放入指定目录，系统会自动进行向量化处理。支持PDF、TXT、Markdown等多种文档格式，通过RAG模块实现精准检索。
Q: 多Agent系统是如何分工的？
A: 系统包含接待员、售后专员、技术支持、主管等角色，通过意图分类自动路由到对应Agent处理，复杂问题可升级到主管协调。
Q: 如何部署到生产环境？
A: FastAPI服务支持Docker容器化部署，配合Nginx反向代理和负载均衡即可实现生产环境部署。详细部署说明请参考项目文档。
Q: 情绪识别的准确率如何？
A: 情绪识别基于LLM语义理解，可识别愤怒、焦虑、不满、开心等7种情绪类型，在实际业务场景中表现出色，并在监控评价模块中持续优化。
