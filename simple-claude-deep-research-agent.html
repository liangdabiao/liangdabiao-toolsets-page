使用方法

简单的三步启动流程

⭐ 为什么选择 Simple 版本？

这是完全小白友好的深度研究工具，无需任何编程基础。只需准备3个Markdown文档，让Claude Code自动创建整个Agent系统，然后一行命令即可开始深度研究。

第一步：准备文件夹

# 创建新文件夹
mkdir my-research-agent
cd my-research-agent

第二步：放入需求文档

将以下3个markdown文档放入文件夹：

  • research_lead_agent.md - 研究主导代理配置
  • research_subagent.md - 研究子代理配置
  • citations_agent.md - 引用代理配置

第三步：初始化并创建

# 在Claude Code中执行
/claude
/init

# 让AI创建agent
"请基于这些markdown文档内容，利用claude code agent技术，
包含subagents、commands、skills等，创建一个deep research claude code agent"

# AI会建立.claude文件夹，包含整个agent

第四步：开始研究

# 一行命令启动深度研究
deep-research 当今NBA最强球员top10

# 研究完成后添加引用
citations
