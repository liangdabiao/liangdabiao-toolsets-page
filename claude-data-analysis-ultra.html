使用指南

简单三步，轻松上手

快速开始

1

放置数据

                                        
# 将数据文件放入 data_storage/ 目录
cp your_data.csv ./data_storage/
# 支持多个 CSV 文件
2

运行分析

                                        
# 全自动互联网数据分析（推荐）
/do-more

# 或交互式完整分析
/do-all
3

查看报告

                                        
# /do-more 输出
open do_more_analysis/integrated_results/Comprehensive_Analysis_Report.html

# /do-all 输出
open complete_analysis/final_report/
