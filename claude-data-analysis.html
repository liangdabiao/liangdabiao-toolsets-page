⚡ 斜杠命令示例

基础探索分析

/analyze user_behavior.csv exploratory

对数据集进行探索性分析，发现基本模式

创建可视化

/visualize user_behavior.csv all

生成全面的数据可视化图表

生成分析代码

/generate python data-cleaning

生成数据清洗的Python代码

数据质量检查

生成研究假设

🔄 数据分析工作流

1

数据准备

将CSV、JSON或Excel文件放入data_storage目录

2

探索分析

使用/analyze命令进行初步数据探索

3

创建可视化

通过/visualize命令生成洞察图表

4

生成报告

使用/report命令创建完整分析报告

📋 使用示例：用户行为分析

# 完整分析工作流 /analyze user_behavior.csv exploratory /visualize user_behavior.csv trends /quality user_behavior.csv clean /report user_behavior.csv complete html /generate python user-segmentation

一组命令即可完成从数据探索到代码生成的完整分析流程

🏗️ 项目结构

claude-data-analysis/
├── .claude/
│   ├── agents/          # 子代理配置
│   ├── commands/        # 斜杠命令定义
│   ├── hooks/          # 自动化脚本
│   └── settings.json   # Claude Code 设置
├── data_storage/       # 数据文件存储
├── visualizations/     # 生成的图表
├── generated_code/     # 分析代码
├── analysis_reports/   # 分析报告
├── examples/          # 示例数据集和工作流
└── docs/             # 文档
