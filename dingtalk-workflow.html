为什么做这个？

将分散在十几个SaaS工具中的效率工作流，全部收敛到钉钉一个平台

核心思想

用钉钉作为统一的数据底座和交互界面，用 Claude Code/Codex/Workbuddy 作为智能调度中枢，把原本分散在 Gmail、Telegram、Todoist、Slack 等十几个 SaaS 工具中的个人效率工作流，全部收敛到钉钉一个平台内运行。每个工作流被封装为一个 Claude Code/Codex/Workbuddy Skill（SKILL.md），通过自然语言对话或指令触发，调用 dws 操作钉钉 API 完成数据读写、消息通知、任务创建等操作。

钉钉独有优势（飞书版没有的功能）

OA审批系统集成 -- 晨间简报和商业分析可直接展示审批状态；考勤打卡数据 -- 健康日记可关联作息规律；工作日志(report) -- 晨间简报可展示日志摘要；DING紧急消息 -- 重要通知确保触达；开放平台文档搜索(devdoc) -- 内容创作管道增加技术研究来源。

10大工作流 Skill

自然语言驱动，覆盖个人效率全场景

📰

Skill 1: 每日晨间简报

整合钉钉日历、待办、OA审批、考勤、日志等数据，生成今日综合简报。支持发送到群聊、DING紧急发送、定时自动生成。

📋

Skill 2: 会议待办追踪

从会议中提取待办事项，通过消息确认后自动创建待办并追踪进度，确保每次会议的行动项不遗漏。

👥

Skill 3: 个人CRM

联系人管理与关系热度追踪，记录每次互动，智能提醒维护重要人脉关系，构建个人社交网络图谱。

📚

Skill 4: 个人知识库

链接保存、摘要提取、智能搜索，用钉钉AI表格索引替代传统知识库工具，快速积累和检索知识。

📱

Skill 5: 社交媒体追踪

管理社交媒体账号，追踪粉丝增长和内容表现趋势，每日快照记录，分析增长数据给出优化建议。

✍️

Skill 6: 内容创作管道

创意评估到方案再到执行的完整内容创作流程，支持技术文档搜索和多种内容形式。

📈

Skill 7: 股票研究助手

自选股监控、深度研究报告生成，利用AI WebSearch获取实时行情数据，辅助投资决策分析。

💼

Skill 8: AI商业顾问团

8位AI顾问综合分析，从不同角度审视商业问题，读取多个Skill数据生成综合商业分析报告。

🤖

Skill 9: 多编程代理协同

竞赛/分工/流水线多种编程模式，多个AI代理协同完成复杂开发任务，提升编码效率。

💪

Skill 10: 健康日记

记录饮食和身体状态，AI自动发现食物与健康的隐藏关联，支持照片识别记录和健康周报生成。

安装与配置

简单几步，开启钉钉AI效率之旅

1. 确认环境就绪

检查 dws 版本和登录状态：

# 检查 dws 版本
dws --version

# 检查登录状态
dws auth status --yes -f json

# 检查 Skill 是否就位
ls .claude/skills/dingtalk-workflow-*/
2. 环境要求

确保以下组件已安装：

# Claude Code/Codex/Workbuddy  CLI 工具
# dws (钉钉 CLI) v1.0.0+，已全局安装
# 钉钉应用已在钉钉开放平台创建并开通 CLI 访问权限
# 已通过 dws auth login 完成登录
# Node.js（dws 依赖）
3. 选择 Skill 开始使用

每个 Skill 首次使用时会自动引导完成数据初始化：

你：今天有什么安排？
你：午餐吃了红烧牛肉面和一杯冰美式
你：帮我保存这篇文章到知识库 https://example.com/article
你：添加 AAPL 到自选股，目标价 200
4. 按需初始化

也可以主动触发初始化：

你：帮我初始化个人CRM系统
你：初始化健康日记
你：设置晨间简报

常见问题

关于钉钉AI效率系统的常见疑问

Q: 需要什么前置条件？
A: 需要安装 Claude Code/Codex/Workbuddy CLI、dws 钉钉 CLI v1.0.0+，并在钉钉开放平台创建应用并开通 CLI 访问权限，然后通过 dws auth login 完成登录。
Q: 与飞书版本有什么区别？
A: 将飞书版本的10大工作流完整迁移到钉钉生态，并增加了钉钉独有功能：OA审批集成、考勤打卡数据、工作日志、DING紧急消息、开放平台文档搜索。
Q: Skill之间数据能联动吗？
A: 可以。例如晨间简报会读取日历、待办、OA审批、考勤、CRM、社交数据等；商业顾问团会读取多个Skill的数据生成综合分析报告。
Q: 如何实现定时自动化？
A: 支持 CronCreate 配置定时任务，例如工作日早上8点自动生成晨间简报并发送到指定群聊。
Q: 数据存储在哪里？
A: 所有数据统一存储在钉钉AI表格中，配置信息持久化到 Claude Code/Codex/Workbuddy memory，跨会话保留。
