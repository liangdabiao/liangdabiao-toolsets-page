8阶段研究框架

专业投资尽调方法论

1

业务基础

公司事实底座：产品、收入构成、客户、价值链、战略定位

2

行业分析

行业周期、供需关系、竞争格局、政策影响

3

业务拆解

业务分部、盈利引擎、定价能力、经济特征

4

财务质量

指标趋势、现金流vs利润、风险信号、同行对比

5

股权治理

股权结构、管理层、资本配置、ROIC分析

6

市场分歧

多头观点、空头观点、关键争议、验证节点

7

估值护城河

护城河评级(0-5)、相对估值、绝对估值、风险分析

8

综合报告

信号评级、投资论点、监控清单

负债比率, 现金跑道, 催化剂时间线

使用指南

简单命令，专业研究

# 启动 Claude Code
claude

# 设置模型（可选但推荐）
/model opus

# 执行股票研究
/stock-research [股票代码或公司名称]

# 示例：
/stock-research 600519              # 贵州茅台 (A股)
/stock-research AAPL                # 苹果公司 (美股)
/stock-research 腾讯 00700.HK        # 腾讯控股 (港股)
用户
/stock-research 贵州茅台 600519
