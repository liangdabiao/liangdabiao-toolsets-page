核心理念

一个平台，统一管理所有工作流

用飞书作为统一数据底座和交互界面

用飞书作为统一的数据底座和交互界面，用 Claude Code 作为智能调度中枢，把原本分散在 Gmail、Telegram、Todoist、Slack、Asana 等十几个 SaaS 工具中的个人效率工作流，全部收敛到飞书一个平台内运行。每个工作流被封装为一个 Claude Code Skill（SKILL.md），通过自然语言对话或指令触发，调用 lark-cli 操作飞书 API 完成数据读写、消息通知、文档生成等操作。

安装与配置

简单几步，搭建你的个人 AI 效率系统

1. 确认环境要求

确保已安装 Claude Code CLI 和 lark-cli：

# 检查 lark-cli 版本
lark-cli --version

# 检查登录状态（一次授权所有模块）
lark-cli auth login --domain im,calendar,task,mail,base,docs,wiki,drive,vc,minutes,contact,sheets
2. 克隆项目

获取项目代码和 Skill 文件：

git clone https://github.com/liangdabiao/lark-workflow-feishu-cli.git
cd lark-workflow-feishu-cli

# 检查 Skill 是否就位
ls .claude/skills/lark-workflow-*/
3. 开始使用

用自然语言触发工作流：

# 查看今天的安排
你：今天有什么安排？

# 记录饮食
你：午餐吃了红烧牛肉面和一杯冰美式

# 保存文章到知识库
你：帮我保存这篇文章到知识库 https://example.com/article
4. 按需初始化

首次使用某个 Skill 时，AI 会提示创建所需的多维表格：

# 主动初始化各类系统
你：帮我初始化个人CRM系统
你：初始化健康日记
你：设置晨间简报

常见问题

关于飞书AI效率系统的常见疑问

Q: 需要哪些前置条件？
A: 需要安装 Claude Code CLI 工具和 lark-cli 命令行工具，并拥有飞书企业版账号。首次使用需通过 lark-cli auth login 完成登录授权，授权所有需要使用的飞书模块。
Q: 支持哪些飞书模块？
A: 支持 IM 消息、日历、任务、邮箱、文档、知识库、多维表格、电子表格、通讯录、妙记、云空间、视频会议等飞书全生态模块。
Q: 如何抓取社交网络数据？
A: 推荐配合 Apify Agent Skills 或 tikhub_api_skill 使用，可从 GitHub 安装对应 Skill，实现社交媒体数据自动抓取和分析。
Q: 各 Skill 之间如何联动？
A: 各 Skill 通过共享飞书多维表格实现数据联动。例如，CRM 中维护的联系人会自动出现在会议待办追踪、晨间简报等相关 Skill 中。
Q: 是否支持定时自动化？
A: 支持定时自动化配置，可以设置晨间简报定时推送、任务状态定时播报、审批催办定时检查等自动化任务。
Q: 需要 OpenClaw 吗？
A: 本项目同时适配 Claude Code Skill 和 OpenClaw，两种框架均可使用。Claude Code 用户直接使用 SKILL.md 即可，OpenClaw 用户按照 OpenClaw 规范加载即可。
