安装与使用

快速开始

1. 克隆项目
git clone https://github.com/liangdabiao/crewai_stock_analysis_system.git
2. 安装依赖
pip install -r requirements.txt
3. 启动服务
python app.py  # 或按项目文档启动 Web 服务
4. 打开管理界面
浏览器访问本地服务地址，添加股票即可开始分析
