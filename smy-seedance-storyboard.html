为什么做这个？

让 AI 不再跑偏成"假上美影"，把好故事变成能直接出片的制作文档

🎬 上美影短剧制作的痛点

直接让 AI 生成上美影风格视频，画面常常跑偏成油画感的"假上美影"——出现阴影、渐变、3D 体积感， 失去纯 2D 平涂的手工味道。同时跨集制作时颜色容易跑色，角色造型难以保持一致， 编导需要逐帧手填分镜表、来回调提示词，效率低下。这个项目把"风格咒语、色盘、狠命令、尾帧衔接" 等实测机关固化进 Skill，一句话需求就能产出五件套制作文档，让即梦/Seedream 出图、Seedance 2.0 出片全程稳定可控。

专剧专色盘

素材出图清单

角色(C01-C99)、场景(S01-S99)、道具(P01-P99)编号提示词，贴到即梦/Seedream/豆包直接出图，Midjourney用英文对照版

🎬

每集分镜脚本

Seedance 2.0专用时间轴格式(0-3s/3-6s/6-9s/9-12s/12-15s)，首行固定上美影风格行+色盘，整段粘贴即可出片

🔗

尾帧无缝衔接

每集最后一帧画面描述，下一集起把上一集视频传上去选"延长"，集与集画面无缝衔接

🎭

上美影风格咒语

固定风格块贴在每条提示词开头+结尾两句狠命令（必须纯2D平涂！绝对不要阴影渐变3D体积感！），防止AI跑偏成油画感假上美影

🖼️

风格不跑偏的核心机关

1. 风格咒语
每条提示词开头贴一段固定的上美影风格块，定义手绘墨线、水粉平涂、矿物颜料色、胶片颗粒感
2. 结尾狠命令
结尾两句狠命令：必须纯2D平涂！绝对不要阴影、不要渐变、不要3D体积感！必须大面积留白！没有它AI容易渲染成油画感假上美影
3. 一剧一色盘
所有提示词逐字引用同一串颜色名，跨集不跑色；角色用专属主色+专属纹样+怪色点缀区分
4. 视频延长衔接
第一集直接生成，第二集起把上一集视频传上去选"延长"，尾帧描述保证集与集画面无缝衔接

安装与配置

作为 Claude Code Skill 使用，几步开始上美影短剧创作

1. 克隆项目

获取 Skill 源码：

git clone https://github.com/liangdabiao/smy-seedance-storyboard.git
cd smy-seedance-storyboard
2. 安装到 Skill 目录

将项目放入 Claude Code 的 skills 目录：

# 复制到 .claude/skills/ 下
cp -r smy-seedance-storyboard ~/.claude/skills/
3. 在 Claude Code 中调用

通过 skill 命令启动上美影短剧生成流程：

/skill smy-seedance-storyboard
4. 提供故事并回答问题

说一句话提需求（如"做一个武松打虎的上美影短剧，5集"），回答集数、画幅、基调，不想答就说"都用默认"。

5. 拿文档去平台干活

拿素材清单去即梦/Seedream出图，拿每集分镜去Seedance 2.0出片，剪辑软件拼集配旁白和锣鼓点完片。

常见问题

关于上美影风格短剧生成器的常见疑问

Q：出图变成3D/有阴影渐变怎么办？
A：检查提示词结尾的两句狠命令是不是被删了；还不行就追加负面词：不要阴影，不要渐变，不要3D渲染，不要体积光，不要写实照片。
Q：每集多长？多少集合适？
A：每集15秒。故事紧凑用5集（75秒），完整叙事10-20集。
Q：为什么提示词都是中文？
A：默认面向即梦/Seedream/豆包等中文平台。用Midjourney时换素材清单里保留的英文对照版风格块即可。
Q：可以不用上美影风格吗？
A：这个skill就是为上美影而生的，风格是立身之本。其他风格请用通用视频制作流程。
Q：和通用 Seedance 分镜生成器有什么区别？
A：通用分镜生成器面向任意风格视频，本 Skill 专门锁定上美影复古手绘动画风格，内置风格咒语、色盘声明、狠命令、尾帧衔接等机关，确保跨集稳定不跑偏，是为上美影而生的专属工作流。
