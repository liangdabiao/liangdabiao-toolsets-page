为什么做这个？

差距不在模型，在提示词——让视觉大模型替你完成"人肉拆解"

🎯 带货视频复刻的痛点

你写"拍一个好看的视频"，AI给你一坨废片；你写"25岁亚洲女性，黑色齐肩长发，缓慢转身， 嘴角微微上扬，暖光侧逆光，中景缓慢推镜，4K高清，面部不变形"——一次出片。差距不在模型，在提示词。 但编导要逐帧看视频、手填分镜表，效率极低。这个项目用视觉大模型替你完成这套"人肉拆解"： 10秒视频16秒拆完，每一步产出都存档、可检查、可反复用，把"感觉"变成S-A-C-S-C五要素参数。

核心功能

两阶段工作流：先拆解视频成分镜表，再生成提示词包

✂️

视频镜头切分

1fps抽帧+ffmpeg场景切换检测，自动识别剪辑点把视频切成多个镜头，10.1秒广告切4个镜头

🧩

S-A-C-S-C五要素拆解

每镜头取首/中/尾关键帧交视觉模型，按主体/动作/场景/镜头/色彩五要素逐镜头拆解成镜头卡

🔍

全局分析

综合分析产品/品类/带货框架/自然流还是付费流/钩子/卖点/节奏，判断视频整体策略

🎨

三种复刻风格

忠实复刻(faithful)/自然流种草(organic)/千川付费流(paid)三种风格任选，可对同一视频反复生成

📦

完整提示词包

每镜头提示词(≤200字带时间锚点)+完整版整段(≤800字)+中英负面词+@参考图清单+差异说明升级建议

💾

分镜表缓存

storyboard.json按视频sha缓存，拆解每份视频只跑一次，换风格/改产品直接复用分镜表

🎯

单镜头重出

--shot参数只重出指定镜头不动其他镜头，单变量修改法避免全推重来，省积分省时间

🖼️

对照HTML报告

产出自包含HTML，每条镜头提示词旁边摆原片关键帧，浏览器双击打开肉眼核对拆解准不准

为什么分两阶段

阶段一：analyze.py 拆解
1fps抽帧+ffmpeg场景检测切镜头，每镜头取首中尾关键帧交视觉模型做S-A-C-S-C拆解，再综合分析全局，产出storyboard.json缓存，永不重复拆
阶段二：replicate.py 生成
分镜表+风格开关+产品补充信息，一次推理调用（system=编导规则知识库），产出每镜头提示词、完整版、负面词、参考图清单、差异说明，输出md+HTML
为什么不分一步
一次调用做不到既要逐镜头看清楚又要按编导规则约束输出。分两步让中间产物分镜表可人工检查纠错，生成可局部重跑，不每次全凭运气
动作时序链
动作被拆成带箭头的时序链（方法论要求"写慢、写连续、写过程"），表情用物理描述，水印被如实记录作为"不可复刻元素"排除

安装与配置

简单几步，开始复刻爆款带货视频

1. 克隆项目

获取项目代码：

git clone https://github.com/liangdabiao/ecom-video-seedance-prompt.git
cd ecom-video-seedance-prompt
2. 安装依赖

安装 Python 依赖并确保 ffmpeg 在 PATH：

pip install openai
# ffmpeg 需自行安装并加入系统 PATH
3. 配置 DeepSeek API 密钥

写入密钥文件或环境变量：

# 方式一：写入文件首行
echo "你的deepseek_key" > ~/.deepseek_api_key

# 方式二：环境变量
export DEEPSEEK_API_KEY=你的deepseek_key
4. 拆解视频（每视频一次）

10秒视频约16秒拆完，结果缓存：

python scripts/analyze.py "爆款视频.mp4"
5. 生成提示词（三种风格任选）

可反复跑，建议带上产品信息：

python scripts/replicate.py "爆款视频.mp4"                          # 忠实复刻
python scripts/replicate.py "爆款视频.mp4" --style organic         # 自然流种草
python scripts/replicate.py "爆款视频.mp4" --style paid --product "XX品牌精华液"  # 付费流

常见问题

关于带货爆款视频复刻器的常见疑问

Q：为什么不把视频直接丢给模型要提示词，要分两步？
A：一次调用做不到两件事：既要逐镜头看清楚（每镜头单独关键帧分析），又要按编导规则约束输出（知识库作为system注入）。分两步让中间产物分镜表可人工检查纠错，生成可局部重跑，而不是每次全凭运气。
Q：提示词里的品牌名/产品外观靠谱吗？
A：AI只能从画面猜产品。用--product告诉它真实信息（品牌、卖点、色号），生成会以此为准；具体产品外观用@产品参考图占位+"1:1还原"约束，差异说明里会明确列出哪些元素不可控。
Q：口播文案是原片原话吗？
A：不是。模型没有音频模态，口播内容是从字幕和画面推断的（产出中已标注"推断"）。准确口播建议自己补：15秒视频配120字左右，正好符合方法论的最佳字数。
Q：和已有 Seedance 产品有什么区别？
A：本项目专门针对"带货爆款视频复刻"场景：输入一条已有爆款视频，用视觉大模型拆解镜头+全局策略，生成可粘贴即梦的Seedance提示词包，支持忠实/自然流/付费流三种风格切换。区别于从零创作分镜的生成器和纯广告提示词工具，核心是"看懂原片再翻译"。
Q：能处理多长的视频？
A：拆解按1fps（>2分钟自动降0.5fps），镜头多时拆解调用数=镜头数+1。几分钟的视频几十秒拆完；超长素材建议先切出要复刻的片段。
