为什么做这个？

核心理念

通过自然语言驱动企业微信智能表格、文档、日程、待办、消息等能力，实现10大自动化工作流。适合 Claude Agent Skill 和 OpenClaw，用企业微信各模块实现所有工作流功能。将原本分散在多个SaaS工具中的个人效率工作流，全部收敛到企业微信一个平台内运行。

10大工作流 Skill

自然语言驱动，覆盖个人效率和企业协作全场景

💪

Skill 1: 健康日记

记录饮食和身体状态，AI自动发现食物与健康的隐藏关联。支持文字记录、照片识别、关联分析和健康周报生成。自动查询6小时内饮食记录检查关联。

📱

Skill 2: 社交追踪

管理社交媒体账号，追踪粉丝增长和内容表现。支持账号管理、每日快照录入、增长趋势分析和内容表现记录，计算互动率和增长预测。

📋

Skill 3: 会议待办

从会议中提取待办事项，通过消息确认后自动创建待办并追踪。支持批量提取会议待办、单次会议提取，确保每次会议的行动项不遗漏。

👥

Skill 4: 个人CRM

联系人管理与关系热度追踪。记录每次互动细节，智能提醒维护重要人脉关系，构建个人社交网络图谱，支持互动历史查询。

📚

Skill 5: 知识库

链接保存、摘要提取、智能搜索。用企业微信智能表格索引替代传统知识库工具，快速积累和检索知识，支持内容摘要自动生成。

✍️

Skill 6: 内容管道

创意评估到方案再到执行的完整内容创作流程。从想法记录、创意评估、方案撰写到执行追踪的全流程管理。

📈

Skill 7: 股票研究

自选股监控、深度研究报告生成。管理投资组合，追踪4个子表数据：自选股、行情快照、研究报告和交易记录。

📰

Skill 8: 晨间简报

日程 + 待办 + 消息综合简报。读取个人CRM、社交追踪、会议待办等多个Skill数据，生成每日综合简报。

💼

Skill 9: 商业顾问团

8位AI顾问综合分析。从不同角度审视商业问题，读取多个Skill数据生成综合商业分析报告，覆盖战略、财务、营销等维度。

🤖

Skill 10: 多代理协同

竞赛/分工/流水线多种编程模式。多个AI代理协同完成复杂开发任务，支持竞标赛、任务分工和流水线三种协作模式。

数据存储方案

统一存储在企业微信智能表格中

智能表格 (doc_type=10)
所有数据统一存储在企业微信智能表格中，每个Skill自动创建对应的表格和子表。首次使用时自动完成初始化：创建表格、建立子表和字段、保存配置到memory。
文档 (doc_type=3)
分析报告等长文本保存为企业微信文档。支持健康周报、商业分析报告等富文本内容的生成和存储。
Memory 持久化
配置信息（docid、url、sheet_id等）持久化到 Claude Code memory，跨会话保留，后续无需重复配置。

支持的字段类型

字段类型 写入格式 使用场景
TEXT [{"type":"text","text":"值"}] 食物列表、日期、备注
SINGLE_SELECT [{"text":"选项文本"}] 餐次、状态、严重程度
PHONE_NUMBER 直接传字符串 "138xxxx" 手机号
USER [{"userid":"用户ID"}] 参与人

安装与配置

简单三步，开启企业微信AI工作流

1. 安装依赖

全局安装 wecom-cli 和 skills：

npm install -g @wecom/cli
npx skills add WeComTeam/wecom-cli -y -g
2. 配置凭证

交互式输入企业微信机器人配置：

wecom-cli init    # 交互式输入企业微信机器人 Bot ID 和 Secret
3. 使用 Skill

在 Claude Code / OpenClaw 中用自然语言触发：

你：午餐吃了红烧牛肉面和一杯冰美式
你：添加我的 YouTube 账号
你：提取今天所有会议的待办
你：生成本周健康周报
你：分析一下本月 YouTube 的增长趋势
可选：社交媒体数据抓取

常见问题

关于企业微信Agent工作台的常见疑问

Q: 如何开始使用？
A: 安装 wecom-cli，运行 wecom-cli init 配置企业微信机器人凭证，然后在 Claude Code 或 OpenClaw 中用自然语言触发对应 Skill。首次使用时会自动创建智能表格并保存配置。
Q: 数据存储在哪里？
A: 所有数据统一存储在企业微信智能表格（doc_type=10）中，分析报告等长文本保存为企业微信文档（doc_type=3），配置信息持久化到 Claude Code memory。
Q: Skill之间数据能联动吗？
A: 可以。晨间简报会读取个人CRM、社交追踪、会议待办等数据；商业顾问团会读取多个Skill数据；内容管道可选依赖知识库。独立的Skill包括健康日记、会议待办、多代理协同。
Q: 支持哪些企业微信模块？
A: 支持六大核心模块：智能表格（数据存储）、文档（长文本报告）、日程（时间管理）、待办（任务追踪）、消息（即时通讯）、通讯录（联系人管理）。
Q: 首次使用需要手动配置吗？
A: 不需要。所有 Skill 在首次触发时会自动完成初始化：自动创建智能表格、按预设 schema 建立数据结构、将配置保存到 memory。只需用自然语言说即可。
