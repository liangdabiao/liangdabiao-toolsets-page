安装与配置

从证明文本到动画视频

前置条件

Node.js 16+、Python 3.8+、FFmpeg、系统Chrome。可选MiniMax TTS付费或edge-tts免费。

1. 复制模板
cp -R templates/remotion-project/* <new-proof>/
cd <new-proof>
npm install
2. 生成TTS
python scripts/generate_tts.py --provider edge
# 或 --provider minimax 使用付费TTS
3. 渲染输出
npm run render:preview  # 0.5x预览
npm run render         # 1080p最终版

常见问题

Q: 支持哪些数学证明？
A: 支持勾股定理、欧拉公式、积分、几何恒等式、代数不等式等。SVG代码绘制几何，配合LaTeX风格公式面板。
Q: MiniMax和edge-tts哪个更好？
A: MiniMax音质更自然，适合正式教学；edge-tts免费无Key，适合快速预览。两者均完全驱动时间轴。
Q: 为什么用SVG而不是位图？
A: SVG矢量图任意缩放清晰，配合strokeDasharray可实现"绘制动画"，让线条像手写一样出现，效果远优于位图。
