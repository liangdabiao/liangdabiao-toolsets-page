系统架构

基于 MCP 的模块化设计

🎯 Orchestrator Agent

主编排 Agent，协调整个验证流程

📥

Scraper Agent

数据抓取 Agent，通过 XHS MCP Server 抓取小红书笔记和评论

  • 使用业务创意作为搜索关键词
  • 保存 checkpoint: scraping_complete.json
🔍

Analyzer Agent

数据分析 Agent，使用 LLM 分析内容

  • analyze_posts: 分析笔记内容
  • analyze_comments: 分析评论情感
  • comments_tag_analysis: 评论标签分析
  • combined_analysis: 综合分析生成评分
📝

Reporter Agent

报告生成 Agent，生成 HTML 格式报告

  • generate_html_report: 生成 HTML 报告
  • save_report: 保存到 reports/ 目录
  • 保存 checkpoint: report_saved.json

工作流程

四阶段自动化市场验证

1
📥

数据抓取阶段

Scraper Agent 使用业务创意作为搜索关键词，通过 XHS MCP Server 抓取小红书笔记和评论

→
2
🔍

数据分析阶段

Analyzer Agent 分析笔记内容提取用户痛点和需求，分析评论情感和用户反馈，综合分析生成市场验证评分

→
3
📝

报告生成阶段

Reporter Agent 生成 HTML 格式报告，保存报告到 reports/ 目录

→
4
✅

结果输出

返回 TaskResult 包含执行结果，相关资料保存到 agent_context/checkpoints/ 目录

使用指南

简单快速的市场验证

快速开始

1

克隆项目

                                        
git clone https://github.com/liangdabiao/XHS_Business_Idea_Validator.git
cd XHS_Business_Idea_Validator
2

安装依赖

                                        
pip install -r requirements.txt
3

配置 API 密钥

                                        
# 编辑 agent_system/.env 文件
OPENAI_API_KEY=your_key
TIKHUB_TOKEN=your_token
4

运行验证

                                        
python run_agent.py 在深圳卖陈皮

输出文件

                            
reports/{business_idea}_{timestamp}.html
agent_context/checkpoints/{run_id}/
├── scraping_complete.json
├── analysis_complete.json
├── comments_tag_analysis_complete.json
├── combined_analysis_complete.json
└── report_saved.json

项目结构

清晰的模块化代码结构

agent_system/
├── models/                      # 数据模型
│   ├── agent_models.py          # TaskResult, ProgressUpdate
│   ├── context_models.py        # RunContext, ContextQuery
│   └── business_models.py       # KeywordModel, XhsNoteModel
│
├── agents/                      # Agent 核心
│   ├── base_agent.py            # Agent 基类
│   ├── context_store.py         # 上下文存储
│   ├── config.py                # 配置管理
│   ├── orchestrator.py          # 主编排 Agent
│   ├── subagents/               # 子 Agents
│   │   ├── scraper_agent.py     # 数据抓取
│   │   ├── analyzer_agent.py    # 数据分析
│   │   └── reporter_agent.py    # 报告生成
│   └── skills/                  # Skills
│       ├── scraper_skills.py
│       ├── analyzer_skills.py
│       └── reporter_skills.py
│
├── mcp_servers/                 # MCP 服务器
│   ├── xhs_server.py           # 小红书 MCP 服务
│   ├── llm_server.py           # LLM MCP 服务
│   └── storage_server.py       # 存储服务
│
└── tests/                       # 测试
    ├── test_integration.py      # 集成测试
    └── test_e2e.py             # 端到端测试
