EcomImageChat

核心功能

AI驱动的电商视觉创作能力

📷

25个场景模板

白底主图、场景图、平铺图、细节微距、海报、社媒、UGC、模特展示、信息图、爆炸图等全覆盖。

🎨

两种模式

Prompt 模式（只输出 Prompt）+ Generate 模式（调用 API 直接生图），灵活满足不同需求。

🔒

Campaign Style Lock

多图任务自动锁定色板、冷暖调、字体、背景、光线，确保风格一致。

💡

转化驱动力诊断

商品/营销任务自动判断视觉驱动/痛点驱动/情感驱动型。

📦

完整 PDP 图片包

5 张主图 + 7-9 张详情页信息图，一键生成。

🖼️

图片画廊

左侧边栏展示生成图片的缩略图，点击放大预览。

🔍

参考产品图

上传产品照片传入 --image 参数，提升生图一致性。

📊

执行日志

右侧面板显示工具调用实时状态，方便调试和监控。

工作流程

从需求到成品的完整流程

描述产品
→
转化驱动力诊断
→
匹配场景模板
→
生成 Prompt
→
生图/输出
1️⃣

描述需求

用自然语言描述产品和图片需求，AI 自动理解意图。

2️⃣

诊断驱动类型

AI 判断是视觉驱动、痛点驱动还是情感驱动型任务。

3️⃣

匹配模板

根据需求自动匹配最合适的场景模板。

4️⃣

生成 Prompt

基于模板生成专业的图片生成 Prompt，包含颜色码、数字占比、否定清单等。

5️⃣

生图输出

调用 GPT-Image-2 API 直接生成图片，或输出 Prompt 供手动使用。

快速开始

启动 AI 电商视觉创作助手

安装依赖
cd ecom-image-chat
npm install
配置环境变量
# .env（Claude API）
ANTHROPIC_API_KEY=your-api-key
ANTHROPIC_BASE_URL=https://api.deepseek.com/anthropic
MODEL=deepseek-v4-flash
PORT=3006

# .claude/skills/ecom-details-image/.env（图片生成 API）
IMG_BASE_URL=https://api.apimart.ai/v1
IMG_MODEL=gpt-image-2
IMG_API_KEY=your-apimart-api-key
启动开发服务器
npm run dev

浏览器访问 Vite 显示的地址（自动代理到 3006 端口）

生产构建
npm run build
npm start
