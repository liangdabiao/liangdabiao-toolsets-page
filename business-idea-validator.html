🌟 核心功能

💡 商业创意验证

输入任意商业创意，系统自动生成相关关键词并分析市场接受度、竞争激烈程度和可行性

📊 智能数据分析

使用AI模型深度分析用户评论，提取痛点、兴奋信号、竞争对手信息和潜在风险

🌐 多平台数据源

支持小红书、Reddit、Hacker News、公众号等多个平台，集成第三方数据方案如ScraperAPI

📈 可视化报告

交互式图表展示验证评分，生成专业的执行摘要和详细的商业分析报告

🎯 精准市场洞察

基于真实用户反馈分析市场需求，识别趋势机会，为商业决策提供数据支持

⚡ 快速验证流程

从创意输入到验证报告生成，一键完成整个市场调研流程，大幅节省时间和成本

🚀 快速开始

安装步骤

# 1. 克隆项目 git clone https://github.com/liangdabiao/Business_Idea_Validator cd Business_Idea_Validator # 2. 安装依赖 pip install -r requirements.txt # 3. 配置API密钥 # 编辑 business_validator/config.py 配置数据接口 # 编辑 openai_llm.py 配置OpenAI API密钥

使用示例

# 小红书商业调研 streamlit run business_validator_ui_cn.py # Reddit 商业调研 streamlit run business_validator_ui.py # 小红书评论分析 python app.py # Reddit 评论分析 python app_reddit.py

💡 访问 http://localhost:8501 开始使用应用
