使用示例

实际案例展示，了解系统能力

案例：小鹏汽车 IRON 机器人舆情分析

调研目标：深度调研小鹏汽车（XPENG）智能机器人 "IRON" 的舆情情况

数据来源：微博、抖音、小红书、B站、知乎等主流平台

分析维度：

  • 整体舆情情感分析（正面39.2%，负面2.0%）
  • 平台讨论分布（抖音占76.5%）
  • 技术展示关注度分析
  • 产品联动话题热度

输出文件：

  • xpeng_iron_robot_research.py - 调研脚本
  • xpeng_iron_robot_research_raw_data.json - 原始数据
  • xpeng_iron_robot_sentiment_report.md - 简化报告
  • xpeng_iron_robot_sentiment_report_detailed.md - 详细报告（8个章节完整分析）

使用方法

步骤1：在 Claude Code 中输入调研需求

深度调研：小鹏汽车（XPENG）智能机器人 "IRON" 舆情报告，包括媒体新闻，社交媒体帖子，评论等等，写一个完整全面的报告

步骤2：AI自动调用两个Skills进行调研

  • 社媒调研Skill：通过TikHub API抓取多平台数据
  • 深度研究Skill：通过Web Search进行背景调研

步骤3：生成专业的舆情分析报告

安装使用

简单3步，开始使用社媒调研智能体

前置要求

  • 安装 Claude Code
  • 确保版本支持 Agent Skills (1.0+)
  • 获取 TikHub API Key（可选，用于社媒数据抓取）

安装步骤

# 克隆项目
git clone https://github.com/liangdabiao/social_research_agent.git
cd social_research_agent

# 克隆依赖的Skills
git clone https://github.com/liangdabiao/simple_claude_deep_research_agent.git
git clone https://github.com/liangdabiao/tikhub_api_skill.git

# Skills 会自动被 Claude Code 发现
# 确认安装：在 Claude Code 中询问 "What Skills are available?"

使用方法

直接在 Claude Code 中用自然语言描述你的调研需求，系统会自动调用两个Skills进行协同工作。例如：

  • "深度调研：某品牌新产品的市场反应和用户反馈"
  • "分析某个话题在各社交平台的讨论情况"
  • "研究某公司的品牌形象和用户口碑"
