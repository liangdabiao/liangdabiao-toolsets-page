🎨 传统故事视频制作的痛点

手工制作故事短视频门槛很高：要会画分镜、要付费的视频/配音 API、字幕渲染难做到确定性一致。 常见的 AI 视频方案要么靠静帧翻页观感呆板，要么让视频模型直接画文字导致画面乱码中文， 要么依赖昂贵的图生视频接口。本 Skill 用「先 TTS 定时长，再纯文生视频」的方法论， 每场直接生成会动的视频片段，字幕永远由 Remotion 确定性渲染（MaShanZheng 毛笔字）， 全程 Agnes + edge-tts 免费，真正做到零成本、可复用、一句话触发。

核心功能

从故事文本到 9:16 竖屏手绘蜡笔风短视频的全流程能力

🎬

纯文生视频

每场直接调用 Agnes Video V2.0 生成一段会动的视频片段，画面自带运动；不用静帧、不用擦除、不用翻页，告别呆板观感。

🖌️

手绘蜡笔风

默认 --style crayon：Q 版蜡笔色 + 记号笔轮廓，童话 / 生活 / 日记题材首选，三段式 prompt 拼接固定风格头 + 动作主体 + 运动尾。

📖

英文教学模式

--style textbook 切换 Oxford 教材叙事插画风，由 TeachingCard.tsx 确定性叠加透明教学卡（关键词 / IPA / 释义 / 定义 / 例句），专做英语课文听力词汇视频。

🔊

免费 TTS 旁白

音频后端固定 edge-tts，免费、无需 API key。中文默认 zh-CN-XiaoyiNeural，英文 en-US-JennyNeural，在 narration.yaml 配置 voice / speed 即可。

✍️

毛笔字字幕

字幕永远由 Remotion 确定性渲染（MaShanZheng 毛笔字），prompt 里 negative 强制排除画面文字，禁止让视频模型画中文，杜绝画面乱码。

⏱️

TTS 定时长

ffprobe 量每段旁白真实时长，按 24fps、8n+1 规则算 num_frames（上限 441 ≈ 18.3s），先定时长再生成视频，时序精准对齐。

🎯

9:16 竖屏成片

720×1280 预览即默认成片，npm run render:preview 一键出片；需要高清时 npm run render 输出 1080×1920，适配手机短视频平台。

💰

全免费方案

Agnes Video V2.0 当前 $0/秒 + edge-tts 免费，整体零成本。免费 key 限流 1 req/min，默认 --concurrency 1 串行，429 自动等 65s 重试不中断。

核心环节说明

1. 故事切句与 TTS
一句一拍，英文按 . ! ? ; 切、中文按 。！？；切，单句有字符上限，自然段空行分隔。每句对应一场视频，调用 edge-tts 生成旁白音频。
2. 时长反算帧数
ffprobe 量每段旁白真实时长，按 24fps 与 8n+1 规则计算 num_frames（上限 441 ≈ 18.3s）。旁白过长则提示在 story.txt 拆短句子。
3. 逐场纯文生视频
每场 prompt 三段式拼接：固定风格头 STYLE_HEADER + 该场动作主体 + 固定运动尾 MOTION_FOOTER（locked camera / paper cutouts / no drift），调 Agnes Video V2.0 异步任务 + 轮询出 mp4。
4. Remotion 确定性渲染
Remotion 4.x 组装视频片段 + MaShanZheng 毛笔字字幕 + 音轨，textbook 模式再叠加透明教学卡。720×1280 预览即成片，按需升 1080×1920。

安装与配置

作为 Skill 安装，一句话触发视频生成

1. 安装 Skill

在 workbuddy、codex、Claude Code 中直接命令要求安装：

在 workbuddy, codex, claude code，直接命令要求安装 skill:
https://github.com/liangdabiao/story-handdrawn-video
2. 安装依赖

进入项目目录后用原生 npm 安装（rtk npm install 会失败）：

npm install
3. 生成视频

中文故事默认蜡笔风；英文教学用 textbook 风格：

python scripts/gen_story_videos.py story.txt --title "我的小猫"

python scripts/gen_story_videos.py story.txt \
  --title "CQ001 What is the supreme law" \
  --style textbook --lang en \
  --teaching-content teaching_content.json
4. 渲染成片

720×1280 预览即默认成片，需要高清时跑 render：

npm run render:preview   # -> out/story-preview.mp4
npm run render           # -> out/story.mp4 (1080x1920)
5. 配置 Agnes API Key（可选）

视频后端固定 Agnes Video V2.0，免费 key 申请地址 https://agnes-ai.com/，限流 1 req/min，音频后端 edge-tts 无需 key。

常见问题

关于故事手绘视频生成器的常见疑问

Q: 生成一段视频要花多少钱？
A: 视频用 Agnes Video V2.0 当前 $0/秒，旁白用 edge-tts 免费、无需 API key，整体零成本。免费 key 限流 1 req/min，每段 30s–2.5min，15 段约 15–40 分钟。
Q: 视频里出现乱码中文/英文怎么办？
A: 说明该场 prompt 漏了 negative。不要重跑整轮，把缺失项写进下一场的 negative 即可；已有片段按 70% 接受，或只删那一个 <sid>.mp4 单跑。
Q: crayon 和 textbook 风格怎么选？
A: 默认 --style crayon 适合中文童话 / 生活 / 日记；--style textbook 适合英语课文 / 听力 / 词汇教学，会用 TeachingCard 叠加关键词、IPA、释义、定义、例句的透明教学卡。
Q: 旁白超过 18 秒画面会怎样？
A: num_frames 上限 441（≈18.3s @ 24fps），旁白过长画面会早结束。解决办法是在 story.txt 里把长句拆短，一句一拍、单句不超字符上限。
Q: 可以用自己录好的 mp3 + LRC 吗？
A: 可以。用 slice_from_lrc.py 切片，再 gen_story_videos.py --skip-tts --paragraph-beats 跳过 TTS，适合自带专业录音和 LRC 的教学片。
