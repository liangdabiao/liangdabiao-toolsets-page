简历批评家

一个 AI 简历深度优化助手。把你的简历和目标岗位的 JD（职位描述）发给它，它会像一个资深的 HRBP + 技术面试官一样，帮你找出简历的问题，给出修改建议，并直接交付一份优化后的简历。

为什么做这个？

投简历之前，让 AI 像资深 HR 一样先帮你审一遍

📄 简历优化的痛点

投简历前没人帮你看一眼，面试没过不知道差在哪，想换方向不确定简历能不能匹配目标岗位， 简历写好了想从 HR 视角找找毛病。传统简历工具只能做排版，不能结合具体 JD 做深度匹配分析， 更不会直接交付一份改好的简历。你需要的是一个懂招聘、懂技术、还能动手改简历的"批评家"。

核心原理与步骤

1. 第一印象判断
模拟 HR 快筛场景，30 秒内判断简历能否过筛，给出最直接的"留/弃"判断与核心理由。
2. 地毯式审计
逐条指出简历中的问题，每条都带可执行的修改建议，从措辞、量化、关键词到结构全覆盖，不留死角。
3. 修改蓝图
给公式、给例子、给启发式问题，授人以渔——让你理解改动的底层逻辑，下次自己也能写更好。
4. a4cv 微调衔接
优化后的简历以 Markdown 形式交付，可一键导入 a4cv 编辑器继续精修排版，再导出为最终 PDF。

安装与配置

只需一个 Python 依赖，即可启动完整流程

1. 克隆 skill 仓库

获取 skill 文件：

git clone https://github.com/liangdabiao/resume-matcher-skill.git
cd resume-matcher-skill
2. 安装依赖

仅 PDF 解析需要 pdfminer.six；DOCX 与纯文本可不装：

pip install -r ".agents/skills/resume-matcher/requirements.txt"
3. 启动 a4cv 可视化编辑器

需要 Python，无需额外安装：

python ".agents/skills/resume-matcher/scripts/serve.py"
4. 访问编辑器

在浏览器中打开：

http://localhost:8765/a4cv/

常见问题

关于简历批评家 skill 的常见疑问

Q: 需要外部 API Key 吗？
A: 不需要。skill 使用 AI 自身的推理能力，零外部 API Key 即可工作。仅 PDF 解析需要安装 pdfminer.six。
Q: 支持哪些简历格式？
A: 支持 PDF、DOCX、纯文本三种格式。图片格式的简历（扫描件/JPG/PNG）无法解析文字，加密 PDF 也无法处理。
Q: 没有现成 JD 可以用吗？
A: 可以。告诉 AI 你想投什么岗位，AI 也可以基于岗位描述帮你分析；JD 越详细，分析越精准。
Q: 和 resume-matcher-agent-cn 是什么关系？
A: 两者形态不同：resume-matcher-agent-cn 是 Next.js + FastAPI 全栈 Web 应用；本仓库是 Skill 形态，作为 AI Agent 的技能包加载，更轻量，可直接在 Agent 对话中调用，无需部署服务。
Q: 可以多次优化同一份简历吗？
A: 可以。针对不同岗位反复优化同一份简历，每次都生成独立的审计报告与优化版本，配合 a4cv 编辑器微调最终排版。
