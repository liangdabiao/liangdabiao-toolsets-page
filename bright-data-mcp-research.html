实战案例

基于真实数据的市场调研案例展示

案例1：3D打印机市场研究报告

调研目标：详细的亚马逊3D打印机市场分析

数据来源：Amazon电商平台产品数据

分析维度：

  • 市场规模和增长预测
  • 畅销产品排行榜
  • 品牌市场份额分析
  • 技术趋势和消费者行为
  • 定价策略和利润分析
  • 竞争格局评估

输出文件：

  • amazon_3d_printer_research_report.md - 完整市场研究报告

案例2：便携式电源站市场数据

调研目标：结构化的便携式电源站市场数据分析

数据来源：Amazon电商平台产品数据

分析内容：

  • 主要品牌产品规格对比
  • 容量、输出功率、重量和价格数据
  • 市场细分和趋势分析
  • 主要品牌（Jackery、EcoFlow、Bluetti、Anker、Goal Zero）的竞争分析

输出文件：

  • portable_power_station_data.json - 结构化市场数据

使用方法

步骤1：确保已配置有效的 Bright Data API 密钥

步骤2：使用 Claude AI 运行研究查询

步骤3：利用 research-brightdata 技能进行综合市场分析

步骤4：将新的研究数据保存为JSON或Markdown格式

安装使用

简单配置，开始使用专业级电商调研工具

前置要求

  • 安装 Claude Code/Codex/Workbuddy
  • 确保版本支持 Agent Skills (1.0+)
  • 获取 Bright Data API 密钥（用于网络爬虫）

项目结构

D:\new_bright_data\
├── amazon_3d_printer_research_report.md  # 3D打印机市场研究报告
├── portable_power_station_data.json      # 便携式电源站数据
├── .mcp.json                             # MCP服务器配置
├── .claude/                              # Claude AI配置
│   ├── settings.local.json               # Claude权限设置
│   └── skills/                           # Claude技能
│       ├── ducksearch/                   # DuckDuckGo搜索技能
│       └── research-brightdata/          # Bright Data研究技能
└── QWEN.md                               # 项目说明文档
