🌟 核心功能

📥 Ingestion（数据摄取）

集成多个AI处理API（OpenAI、Tavily Search）和数据抓取工具，支持小红书、微信公众号等多平台数据采集

🔄 Transform（数据加工）

非结构化到结构化的数据清洗和转换，确保数据准确性和一致性，支持向量化和RAG处理

🔍 Explore（探索分析）

多种数据库支持，灵活的数据存储和查询，包括MongoDB文档存储、PostgreSQL关系型数据库等

📊 Retrieve（查询检索）

NL2SQL自然语言查询、LangGraph RAG框架、多模态图片检索，FastAPI RESTful API接口

🚀 快速开始

1. 环境配置

将 data.env-dev 改为 .env，配置必要参数：

# AI Service APIs OPENAI_API_KEY=your_openai_key OPENAI_MODEL=gpt-4.1-mini TAVILY_API_KEY=your_tavily_key # Database Connections MONGO_URI=mongodb://localhost:27017 POSTGRES_USERNAME=myuser POSTGRES_PASSWORD=mypassword POSTGRES_DB=mydatabase # Cloud Storage ALIYUN_OSS_ACCESS_KEY_ID=your_oss_key ALIYUN_OSS_BUCKET_NAME=your_bucket_name # Web Scraping XHS_AUTH_TOKEN=your_xhs_token GZH_AUTH_TOKEN=your_gzh_token SCRAPING_INTERVAL=3600

2. 数据库环境安装

# Python conda环境 conda create -n env_310 python=3.10 conda activate env_310 # Docker部署 # PostgreSQL docker run --name my-postgres \ -e POSTGRES_USER=myuser \ -e POSTGRES_PASSWORD=mypassword \ -e POSTGRES_DB=mydatabase \ -p 5432:5432 \ -d postgres # MongoDB docker run -d --name mongodb -p 27017:27017 mongo # ChromaDB docker run -d --name chroma \ -p 8000:8000 \ -v chroma-data:/data \ chromadb/chroma # 本地安装 pip install chromadb

💡 ChromaDB测试：
import chromadb
client = chromadb.PersistentClient(path="VECTOR_DB_DIRECTORY")

3. 依赖安装和服务启动

# 安装依赖 pip install -r requirements.txt # 启动服务 python rest_api/main.py # 测试功能 python -m rag_graphs.gzh_rag_graph.ingestion # 测试RAG python -m scraper.xhs_scraper # 测试爬虫 # 访问服务 http://localhost:8000

4. 定时任务配置

在 rest_api/main.py 中设置数据处理定时任务：

# 设置定时任务 from rest_api.main import scrape_in_interval, run_scrapers_in_background # 配置抓取间隔（秒） scrape_in_interval(interval: int=3600) # 后台运行爬虫任务 run_scrapers_in_background()

⚡ 可以根据需要自定义定时任务的执行间隔和数据源配置

在 GitHub 上查看源代码 开始构建AI数据中心
