为什么需要自然语言绘图？

让数学描述直接变成可交互图形

对话式数学可视化，降低绘图门槛

传统GeoGebra需要用户学习命令语法，门槛较高。本工具通过自然语言对话，让用户描述"画一个三角形并作外接圆"，AI自动生成并执行GeoGebra命令，输出可拖拽/缩放/旋转的交互图形，特别适合教学演示、数学探索、几何研究等场景。

安装与配置

Bun一键启动开发环境

前置条件

Bun运行时、OpenAI兼容API Key（DeepSeek、Qwen、GPT等）。

1. 克隆项目
git clone https://github.com/liangdabiao/Geogebra-WebChat.git
cd Geogebra-WebChat/geochat-web
2. 安装依赖
bun install
3. 启动服务
bun run proxy   # LLM代理（注入API Key）
bun run dev     # Vite开发服务器 → http://localhost:5173

常见问题

Q: 支持哪些AI模型？
A: 所有OpenAI兼容API：DeepSeek、Qwen、GPT、Claude等。可在配置中切换。
Q: GeoGebra功能完整吗？
A: 使用GeoGebra官方CDN（deployggb.js），功能与官方完整版一致，支持2D/3D几何、代数、统计等全功能。
Q: API Key安全吗？
A: Key通过Bun代理服务端注入，浏览器永远无法接触到原始Key，安全可靠。
