核心功能特性

基于 Graph of Thoughts 框架的专业级深度研究系统

🧠

Graph of Thoughts 框架

基于图结构的推理路径管理，支持平衡、深度优先、广度优先三种研究模式，智能优化研究路径。

⚙️

7阶段深度研究流程

问题细化、研究规划、多智能体研究、信息收集、综合分析、引用验证、报告生成。

🤖

多智能体架构

Web研究Agent（3-5个）、学术/技术Agent（1-2个）、交叉引用Agent（1个）并行协作。

⭐

A-E质量评级系统

A级同行评审、B级队列研究、C级专家意见、D级预印本、E级轶事推测。

🔗

引用验证机制

每个事实声明必须包含作者/组织、发布日期、来源标题、URL/DOI、页码。

📊

结构化输出

生成1-2页执行摘要、20-50页完整报告、数据、图表、来源、研究笔记、附录。

🚀

简单易用

仅需一个命令 /deep-research [主题]，全程自动化完成深度研究。

⚡

灵活配置

支持全球范围、时间范围、来源类型、报告格式等多种研究参数定制。

7阶段研究流程

系统化的深度研究方法论

1
问题细化

分析研究主题，识别关键问题，制定研究范围和目标

2
研究规划

制定详细的研究计划，确定信息来源和研究策略

3
多智能体研究

启动多个专业Agent并行研究不同方面

4
信息收集

从多个来源收集相关数据和文献

5
综合分析

整合收集的信息，进行深度分析和交叉验证

6
引用验证

验证所有引用的准确性和可靠性

7
报告生成

生成结构化的研究报告和可视化结果

同行评审期刊/预印本

使用方法

简单命令，自动化研究

# 启动深度研究
/deep-research 人工智能在医疗领域的应用现状和未来趋势

# 指定研究参数
/deep-research 量子计算最新进展 --time-range=1year --region=global

# 指定报告格式
/deep-research 区块链技术分析 --format=detailed --include-charts

安装步骤

1. 克隆项目

git clone https://github.com/liangdabiao/Claude-Code-Deep-Research-main.git
cd Claude-Code-Deep-Research-main

2. 安装依赖

npm install

3. 配置环境

# 复制配置文件
cp .env.example .env

# 配置 API 密钥
# ANTHROPIC_API_KEY=your_key_here

4. 启动使用

/deep-research 您的研究主题
