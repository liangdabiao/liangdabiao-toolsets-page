核心功能

TikTok Shop全维度数据分析

📦

商品分析

新品榜、销量榜、热推榜、视频商品榜，覆盖商品全生命周期数据。

👤

达人分析

涨粉榜、带货榜、蓝V榜、热门榜、黑马榜，发掘潜力达人。

🏪

店铺分析

店铺销量榜、店铺热推榜，找出优质店铺和带货达人最多的店铺。

🎬

直播分析

TT直播榜、直播爆品榜、直播带货达人榜，把握直播风口。

🎵

视频素材

热门视频、热门音乐、热门标签，获取创意灵感。

📣

广告引擎

标签洞察、关键词趋势、热门品类趋势，优化广告投放。

📊

品类大盘

安装配置

快速开始TikTok Shop分析

前置要求
# Kimi WebBridge daemon运行且扩展已连接
~/.kimi-webbridge/bin/kimi-webbridge status
# 期望：running: true, extension_connected: true

# Python 3.8+（无第三方依赖）
# 已登录fastmoss.com的浏览器
快速开始
# 1. 验证守护进程
~/.kimi-webbridge/bin/kimi-webbridge status

# 2. 登录fastmoss.com
# 在Chrome/Edge里打开 https://www.fastmoss.com/ 并登录

# 3. 抓取销量榜Top 50
python .claude/skills/fastmoss-products/scripts/fastmoss_scraper.py \
    --pages 5 --out data/top50.csv

# 4. 生成分析报告
python .claude/skills/fastmoss-products/scripts/analyze.py \
    --top50 data/top50.csv --out-md analysis.md
