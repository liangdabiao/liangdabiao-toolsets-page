为什么做这个？

讲解类视频的制作痛点与白板动画的解决思路

🎬 讲解视频制作的痛点

制作教学讲解视频存在诸多问题：真人录制成本高、需设备场地；通用动画工具学习曲线陡，普通用户难以快速产出； 动画与旁白对齐困难，需手动卡点调整时间轴；现有方案渲染慢、修改一次重渲整段；无法做到「一图逐元素生长」的数学推导/流程图效果。 白板讲解动画 skill 用像素级笔画绘制，帧帧确定、本地零成本、可秒级重渲，并支持元素级 cue 对齐「讲到哪画到哪」，让教学视频制作变得简单可控。

核心功能

从讲解稿到真手绘视频的完整制作能力

✍️

像素级笔画绘制

图形一笔笔描出、文字逐笔写出，真手绘过程呈现。帧帧确定可复现，本地零成本渲染，支持秒级重渲快速迭代

🎯

帧级音画对齐

元素级 cue 对齐「讲到哪画到哪」，旁白与绘制帧级同步。子句 TTS 生成精确 cue 点，确保讲解节奏与画面绘制完美匹配

🖼️

单画布生长模式

一张大图逐元素生长，适合数学推导、流程图、知识图谱。元素按 cue 依次出现，构建复杂的推理过程可视化

📽️

Slide 模式

一拍一图的幻灯片模式，适合步骤讲解、产品介绍、教学课程。每张 slide 独立绘制，切换流畅自然

🔊

多语种旁白

支持中文、英文、任意语种旁白，基于 edge-tts 神经语音合成。自然流畅的发音，无需录制真人配音

🖥️

跨平台支持

支持 macOS、Windows、Linux 三大平台。一键安装脚本自动检测依赖，配置简单开箱即用

🎨

Agnes 白板生图

可选 Agnes API 生成白板底图，配合 CRAFT 文字检测模型自动定位文字区域。无 API key 时用 PIL 程序化绘制兜底

🧪

自检与确定性

内置 self_test.py 自检脚本（CRAFT/渲染/cue对齐三关），毛笔字 MaShanZheng 字体差异化设计，PIL 确定性中文文字层

渲染工作流程

从讲解稿到成片的完整流水线

讲解稿
→
TTS+cue
→
白板生图
→
笔画渲染
→
音画合成

核心流程原理

1. 旁白 TTS 与精确 cue
build_narration.py 子句级 TTS 合成，生成精确 cue 时间点，为后续帧级音画对齐提供时间基准
2. 白板底图生成
gen_board_images.py 调用 Agnes HTTP 客户端生成白板底图（带重试），无 key 时 PIL 程序化绘制兜底
3. 文字层与笔画绘制
make_text_layer.py PIL 确定性中文文字层，CRAFT 模型检测文字区域定位笔画轨迹，render_explainer.py 主渲染
4. 音画帧级合成
按元素级 cue 对齐「讲到哪画到哪」，ffmpeg/ffprobe 系统二进制完成最终 concat 合成成片

安装与配置

简单几步，开始制作白板讲解动画

1. 克隆项目

获取项目代码：

git clone https://github.com/liangdabiao/whiteboard-explainer.git
cd whiteboard-explainer
2. 一键安装依赖

使用 setup 脚本自动安装 pip 依赖与检测系统二进制：

# macOS / Linux
bash scripts/setup.sh

# Windows PowerShell
powershell -ExecutionPolicy Bypass -File scripts/setup.ps1
3. 安装 Skill 到 AI Agent

在 workbuddy、codex、claude code 中安装：

命令要求安装 skill：
https://github.com/liangdabiao/whiteboard-explainer
4. 运行自检

验证 CRAFT 模型、渲染、cue 对齐三关：

python scripts/self_test.py
5. 配置 Agnes API（可选）

配置 AGNES_API_KEY 启用白板生图功能：

# .env 寻找顺序：cwd → 父目录 → ~/.env → ~/.workbuddy/.env
AGNES_API_KEY=your_agnes_api_key_here
# 无 key 时自动用 PIL 程序化绘制兜底

常见问题

关于白板讲解动画 skill 的常见疑问

Q: 能制作真人物或复杂场景视频吗？
A: 不能。白板风不适合真人物、照片、复杂场景，这类需求请用真人视频或别的 skill。本 skill 专注讲解类、推导类、流程图类内容。
Q: 输出分辨率最高多少？
A: 引擎最大输出 1280 长边。如需 8K/超高清，请在 final concat 步骤自行 upscale 提升分辨率。
Q: Agnes API 必须配置吗？
A: Agnes 是付费 API（免费档便宜）。不放 key 时自动用 PIL 程序化绘制兜底，templates/chart-recipes/eclipse.py 是程序化绘制示范。
Q: 支持哪些语种旁白？
A: 支持中文、英文、任意语种旁白，基于 edge-tts 神经语音合成，自然流畅无需录制真人配音。
Q: 有哪些依赖？
A: pip 包：whiteboard-animator、onnxruntime、edge-tts、Pillow、numpy；系统二进制：ffmpeg、ffprobe；可选：AGNES_API_KEY。setup 脚本会自动检测并安装。
