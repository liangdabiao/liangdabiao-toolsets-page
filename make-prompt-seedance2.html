安装与使用

快速开始

1. 安装技能到 AI 助手
git clone https://github.com/liangdabiao/make-prompt-seedance2.git
# 放入 ~/.workbuddy/skills/make-prompt-seedance2/ 或 ~/.claude/skills/
2. 上传参考图
在 codex / workbuddy 等 agent 中上传你的产品白底图或参考视频
3. 说出你的需求
例如：帮我做个抖音带货视频，要抓人、要讲卖点
4. 复制提示词使用
按提示中的上传顺序和 @引用对应关系，粘贴到即梦生成

常见问题

关于 Seedance 2.0 分镜提示词助手 的常见疑问

Q: 写好的提示词在哪些平台能用？
A: 可直接粘贴到即梦（Seedance 2.0）、小云雀、豆包使用，提示词中会说明素材上传顺序与 @引用对应关系。
Q: 完全不会写提示词的人能用吗？
A: 可以。你只需要用大白话描述想做什么视频、上传参考图，结构化提示词由技能自动完成。
Q: 支持写实的真人脸部素材吗？
A: 不支持。该技能面向产品/场景类视频，请注意其能力边界，具体以项目文档为准。
