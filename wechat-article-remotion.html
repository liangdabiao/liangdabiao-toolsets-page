安装与配置

一行命令生成公众号文章视频

前置条件

Node.js 20/22、Python 3.10+、FFmpeg。可选MiniMax T2A v2付费TTS。

1. 创建项目
python3 scripts/scaffold_wechat_article_project.py \
  --project-dir ./my-wx-video \
  --title "示例公众号文章" \
  --article-url "https://mp.weixin.qq.com/s/xxxxx"
2. Agent触发
wechat-article-remotion skill 制作视频：https://mp.weixin.qq.com/s/...
3. 渲染输出
npm install
npm run render
# 输出：1080×1920 @ 30fps 演播厅风格视频

常见问题

Q: 是否支持任意公众号文章？
A: 支持mp.weixin.qq.com/s/...格式的公开文章。需登录或付费墙保护的文章可能无法抓取。
Q: MiniMax和edge-tts如何选择？
A: MiniMax T2A v2音质更自然但需付费；edge-tts免费无Key，适合快速起步。可在配置中切换。
Q: 为什么强调"无PIP"？
A: PIP（画中画）会缩小原文图片，影响阅读。本Skill让原文图片完整占据画面，最大化信息呈现。
