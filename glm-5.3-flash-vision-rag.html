为什么做这个？

把整份资料反复塞给 AI 又贵又慢，需要"先做笔记再翻笔记"

🔍 视觉 RAG 的痛点

直接把整份 PDF 或整段视频反复塞给视觉大模型，既贵又慢——120 页的书每次提问都要全读一遍， 15 秒的视频逐帧分析要烧大量 token。而且答案往往无法核对，模型可能编造。本工具集采用 "先做笔记，再翻笔记"的两阶段漏斗：通读一遍写卡片（每份资料只做一次，永久缓存）， 提问时本地查卡片筛候选（免费），模型只精读命中部分（1次调用）。 120 页的书问一次只需读六七页，省下大量成本，且答案带页码、关键帧、原片对照，可核对不编造。

核心功能

三大视觉技能，从 PDF 到视频到带货提示词的全场景覆盖

📄

PDF 视觉 RAG

把整本 PDF 读一遍建索引，提问秒级回答，答案带页码和原页截图。支持通读型、定位型、细节型问题，兼容扫描版 PDF 与图表表格代码

🎬

视频视觉 RAG

把视频按时间轴读一遍建索引，提问回答带时间戳，能切出可播放片段。输出关键帧 + 短视频片段 + 内嵌播放器的 HTML 预览页

🛒

带货视频→Seedance提示词

拆解带货视频镜头语言，按 S-A-C-S-C 编导方法论生成可直接粘贴进即梦 Seedance 的完整提示词包，含逐镜头对照原片关键帧

⏳

两阶段漏斗省钱

阶段一通读写卡片（每份资料只做一次，永久缓存）；阶段二本地查卡片筛候选（免费），模型只精读命中部分。120页书问一次只读六七页

🔬

两级采样+微观层

平时低密度看全局省 token；问到快速动作时自动对该时刻以 12fps 高密度重新抽帧放大分析，一次甩枪 150 毫秒也不漏

🎨

三种风格一键切换

带货提示词支持 faithful（忠实复刻）、organic（自然流种草）、paid（千川付费）三种风格，一次拆解缓存复用三次生成

✅

💾

指纹缓存复用

索引永远只建一次，缓存键=文件内容指纹，文件一变自动重算。同一条带货视频出三种风格=1次拆解缓存复用+3次生成

深度阅读作答

两阶段核心原理

阶段一：通读写卡片（ingest/analyze）
每份资料只做一次，永久缓存。PDF：每页渲染成图片→视觉模型逐页阅读→每页一张卡片（讲什么/标题/关键词/有无图表）；视频：抽帧→视觉模型逐帧观看→每帧一张卡片（画面有什么/发生了什么/可见文字/运动强度）
阶段二：按卡片定位精读（ask/replicate）
每次只需几秒。你的问题→本地查卡片筛出候选（免费）→模型看图确认（1次调用）→只对命中部分深度阅读作答（1次调用）。省钱的秘密就在这个漏斗：不全读，只读命中的部分
微观层：快速动作高密度采样
问题里含"瞄准/击杀/瞬间/轨迹"这类词会自动触发微观层，对该时刻以 12fps 高密度重新抽帧放大分析，捕捉宏观 1fps 根本看不到的细节，也可手动指定时间窗
指纹缓存：索引只建一次
缓存键=文件内容指纹，文件一变自动重算，文件不变永不重算。同一条带货视频出三种风格=1次拆解缓存复用+3次生成，最大程度复用已有结果

安装与配置

给 AI 你的 GLM key，直接对话使用

1. 克隆项目

获取三个视觉技能源码：

git clone https://github.com/liangdabiao/glm-5.3-flash-vision-rag.git
cd glm-5.3-flash-vision-rag
2. 安装依赖

安装 Python 运行依赖：

pip install -r requirements.txt
3. 配置 GLM API Key

在 codex/workbuddy 等 agent 中给 AI 你的智谱 GLM key：

# 设置智谱 GLM-5.3-Flash API Key
export ZHIPU_API_KEY=your_glm_api_key
4. 加载技能

在 codex/workbuddy 等 agent 中直接给 url 下载 skill：

# 将对应子目录作为 skill 加载到 AI 助手
# glm-5.3-flash-vision-rag        → PDF 视觉 RAG
# glm-5.3-flash-vision-video-rag  → 视频视觉 RAG
# glm-ecom-video-seedance-prompt  → 带货视频→提示词
5. 开始对话使用

直接对 AI 说话即可，例如：扔给它一本 120 页手册问"四种模式是哪四种"； 给它一段录像问"关羽和吕布交战的动作细节"；给它一条爆款广告问"复刻它，改成自然流版本"。

常见问题

关于 GLM-5.3-Flash 视觉 RAG 技能集的常见疑问

Q: 索引建一次要多久？贵吗？
A: PDF 索引（120 页）约 6 次 API 调用、3 分钟；视频索引（15~30 秒短片）1~2 次调用、约 20 秒。索引永远只建一次，永久缓存，文件不变不重算。
Q: 提问一次要花多少？
A: PDF 提问约 2 次调用、十几秒；视频普通提问 2 次调用，动作类触发微观层 3 次调用；带货视频拆解 5 次约 40 秒，复刻提示词生成任一风格 1 次约 80 秒。
Q: 答案能核对吗？会不会编造？
A: 三个技能都遵守"答案必须可核对"约定：PDF 版给原页截图、视频版给关键时刻关键帧和可播放片段、提示词版给逐镜头原片画面对照。只索引前 8 页时追问全书问题，会明确回答"§03 正文不在提供页面中"，不编造。
Q: 无音频理解怎么处理？
A: 视频里的说话声/BGM 内容不在能力范围（音效线索只能从画面推断）。时间戳为采样估计 ±2 秒，要精确请播放切出的片段。超长素材建议先切片处理。
Q: 三种带货风格有什么区别？
A: faithful 忠实复刻最大还原原片；organic 自然流种草追求真实感、补促单镜头、缓节奏；paid 千川付费强钩子、极致特写、快节奏行动号召。一次拆解缓存可复用生成三种风格。
