为什么做这个？

数学概念抽象难懂，传统讲解枯燥催眠，需要动画来讲清楚

📐 学数学的痛点

数学概念往往抽象晦涩，光看公式很难建立直觉。传统教学视频要么炫酷科技风却丢失了数学严谨性， 要么语速平缓催眠让人昏昏欲睡。公式里每个符号到底在干嘛、为什么这样推导， 缺少一种"会动的数学手账"式的呈现方式。本工具专门解决：让 AI 自动把抽象数学概念 变成纸墨质感、中文旁白、逐项巡讲公式的动画短片，画面上每个数字都经过验算，每个"所以"都有前因。

核心原理与步骤

1. 写台词
AI 根据你给的概念，按照纸墨手账风格规范，写出白话化、公式逐项巡讲的中文台词稿
2. AI 配音 + 量时长
调用微软云在线 TTS 为每句台词生成配音，同时精确量出每句话的真实播放时长，作为画面设计的节奏依据
3. 按真实时长设计画面
按每句台词的真实时长设计 Manim 动画：讲局部推近、讲完拉回全景、公式逐项出现，镜头语言与旁白严丝合缝
4. 渲染动画 + 音画合成
Manim 渲染动画视频轨，与配音音轨合成，输出 final.mp4；不满意可指出"第 X 秒节奏太快"，AI 会返工

安装与配置

装好技能后对 AI 说人话，几分钟后拿成片

1. 克隆项目

获取技能源码：

git clone https://github.com/liangdabiao/math-concept-film.git
cd math-concept-film
2. 安装依赖

一条 pip 命令装齐依赖清单：

pip install -r requirements.txt
3. 环境体检

运行体检脚本，缺啥装啥，一步到位：

python scripts/doctor.py
4. 安装到 AI 助手

在 Claude Code / codex / Workbuddy 等 AI 编程助手中安装本技能：

# 将 SKILL.md 作为技能文件加载到 AI 助手
# 或在 codex/workbuddy 中引用本仓库
5. 开始对话使用

对 AI 助手说人话即可，例如："帮我用视频讲清楚傅里叶级数"、"把泰勒公式做成动画"、 "我想看懂特征值到底在干嘛"。AI 会自动走完整条流水线并交付 final.mp4。

常见问题

关于数学概念短片生成器的常见疑问

Q: 一定要联网吗？
A: 配音环节要联网（微软在线 TTS，免费）。渲染动画环节不需要联网，可离线运行。
Q: 能换音色吗？
A: 能。运行 python scripts/tts_lines.py --list-voices 列出全部中文声音， 用 --voice zh-CN-XiaoxiaoNeural 换成晓晓音色。
Q: 能出 1080p 吗？
A: 能。渲染时把 -ql 换成 -qh 即可输出 1080p60（慢一些）。
Q: 英文内容支持吗？
A: 技术上可以（换英文音色+英文台词），但风格的措辞、韵律都是按中文调校的，英文属于"能跑但没调过味"。
Q: 体检报错怎么办？
A: python scripts/doctor.py 的输出会精确告诉你缺什么、复制哪条命令能装上，照做即可。绝大多数问题一条 pip install 解决。
