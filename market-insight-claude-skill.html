三段式框架详解

深度分析，确保洞察质量和可操作性

Stage 1：事实调研

目标：通过多智能体协作，收集市场的基础数据和事实

执行方式：

  • 调研 Agent：利用 WebSearch 和 WebFetch 工具，进行网络调研和专家网络咨询
  • 多源数据：整合行业报告、竞品分析、用户反馈等多维度数据
  • 数据验证：交叉验证关键数据，确保信息准确性和时效性

输出：

  • 市场规模和增长率
  • 目标用户画像
  • 竞争格局分析
  • 技术发展趋势
  • 监管环境评估

Stage 2：结构化洞察

目标：基于调研数据，生成深度商业洞察

执行方式：

  • 洞察 Agent：对收集的数据进行深度分析和模式识别
  • 结构化框架：使用专业分析框架，确保洞察的系统性和全面性
  • 假设验证：对关键洞察进行假设验证和风险评估

输出：

  • 用户核心需求和期望
  • 当前解决方案的最大痛点
  • 解决方案差距分析
  • 未来发展趋势预测
  • 市场竞争胜负手

Stage 3：行动机会清单

目标：将洞察转化为可执行的商业机会

执行方式：

  • 机会 Agent：基于洞察结果，识别和评估商业机会
  • 优先级排序：按照 P0/P1/P2 三个级别对机会进行优先级排序
  • 可行性分析：评估每个机会的执行难度、资源需求和ROI

输出：

  • P0 级机会（必须抓住）
  • P1 级机会（重要但不紧急）
  • P2 级机会（长期观察）
  • 每个机会的执行策略
  • ROI估算和风险提示

输出格式

根据不同需求提供三种格式

执行摘要版

适用场景：快速决策、高管汇报

内容：

  • 核心洞察摘要
  • Top 3 P0级机会
  • 关键数据亮点

完整报告版

适用场景：深度分析、团队研讨

内容：

  • 全流程分析详情
  • 完整的机会清单（P0/P1/P2）
  • 数据支撑和推理过程
  • 详细的风险评估

演示文稿版

适用场景：团队分享、客户演示

内容：

  • 结构化大纲
  • 关键视觉图表
  • 核心要点提炼
  • 行动建议汇总

机会优先级体系

P0/P1/P2 三级机会分类，明确行动优先级

P0 - 必须抓住
高优先级机会
市场空白点、用户迫切需求、技术可行性强、竞争较少的机会。需要立即行动，快速占领市场。
P1 - 重要机会
中优先级机会
市场存在但竞争较多、需求明确但需要更多资源的机会。需要规划，中期布局。
P2 - 长期观察
低优先级机会
市场尚未成熟、技术或政策限制较大的机会。需要持续观察，等待时机。

使用方法

简单几步，获得专业市场洞察

开始使用

前置要求：

  • 安装 Claude Code/Codex/Workbuddy
  • 确保版本支持 Agent Skills (1.0+)
  • 克隆本项目到本地

使用命令：

/market-insight [产品/市场名称]

示例：

  • /market-insight AI写作工具
  • /market-insight SaaS CRM系统
  • /market-insight 电动汽车充电桩

输出选择：

  • 选择输出格式：执行摘要版 / 完整报告版 / 演示文稿版
  • 系统自动生成对应格式的市场洞察报告
