使用场景

实际案例展示，了解系统能力

场景1：露营装备市场商机发现

调研目标：发现露营装备市场的用户痛点和商业机会

关键词：露营, 新手, 装备

数据来源：抖音、小红书、Bilibili等平台

分析结果：

  • 自动识别出"新手不知道买什么"、"装备太贵"、"搭建困难"等核心痛点
  • 发现"轻量化"、"一键搭建"、"高性价比"等未满足需求
  • 生成针对性的产品方案和MVP计划
  • 按优先级排序，快速识别最有潜力的商机

场景2：跨平台竞品分析

调研目标：了解某产品在不同平台的市场反馈

数据来源：抖音、TikTok、小红书三平台对比

分析结果：

  • 对比不同平台的用户痛点和需求差异
  • 识别平台特有的市场机会
  • 发现竞品未覆盖的用户场景
  • 为产品本地化和差异化提供参考

数据质量分级说明

系统会根据数据量自动评估数据质量，帮助判断分析结果的可靠性：

  • Exploratory 探索性（<50条）：样本量小，建议进一步验证
  • Preliminary 初步结论（50-200条）：中等置信度，适合初期研究
  • Reliable 高置信度（≥200条）：统计显著，可作为决策依据

安装使用

简单3步，开始使用SeekMoney AI发现商机

环境要求

  • Node.js >= 18
  • npm 或 pnpm
  • Python 3.x（用于聚类服务）

1. 安装依赖

# 克隆项目
git clone https://github.com/liangdabiao/SeekMoney-ai.git
cd SeekMoney-ai

# 安装 Node.js 依赖
npm install

# 安装 Python 依赖
pip install -r requirements.txt

2. 配置环境变量

# 复制环境变量模板
cp .env.example .env.local

# 编辑 .env.local 文件

# TikHub API 配置 (必需 - 数据采集)
# 注册地址: https://api.tikhub.io/
TIKHUB_API_TOKEN=your_tikhub_api_token_here
TIKHUB_USE_CHINA_DOMAIN=false
TIKHUB_ENABLE_CACHE=true

# LLM API 配置 (必需 - AI 分析)
# 注册地址: https://open.bigmodel.cn/
GLM_API_KEY=your_glm_api_key_here
GLM_MODEL_NAME=glm-4.7
GLM_EMBEDDING_MODEL=embedding-3

3. 运行项目

# 开发模式
npm run dev

# 生产构建
npm run build
npm run start

# 访问 http://localhost:3000

使用方法

  1. 选择数据源（抖音、TikTok、Bilibili、微信视频号、YouTube、小红书）
  2. 输入关键词，多个用逗号分隔，如：露营, 新手, 装备
  3. 可选开启获取视频评论（更耗时但数据更丰富）
  4. 点击开始分析，等待AI处理完成
  5. 查看分析结果，点击任意行查看详细原文
  6. 导出CSV报告或原始数据

💡 提示： TikHub API 按请求计费，约 ¥0.01/次。一次典型分析（3个关键词，20个视频，每个视频30条评论）大约花费 ¥0.5。 支持24小时缓存，重复访问不收费。
