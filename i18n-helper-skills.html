两个互补不重叠的国际化/本地化 skill，覆盖「静态内容站点」和「编程框架源码」两大场景。支持 codex、claude code、workbuddy 等 agent skills。

查看 GitHub 了解更多

核心功能

覆盖静态站点和编程框架两大场景

🌐

html-i18n · 静态HTML站点翻译

扫描HTML提取可翻译文本，生成各语言独立HTML目录，共享CSS与图片资源，零JS依赖，SEO友好。

🔧

i18n-helper · 编程框架源码国际化

扫描源码硬编码文本，按框架生成对应语言文件，替换成翻译函数调用，检查翻译完整性。

✅

简繁转换

内置简繁转换功能，一键生成zh-TW版本，无需额外工具。

📋

翻译完整性检查

检查翻译缺失/空值/完成度百分比，确保翻译质量。

🐍

Python标准库

仅依赖Python标准库，无需pip安装任何第三方包。

🔄

热更新支持

源文件修改后自动更新翻译文件，保持同步。

双Skill对比

如何选择合适的Skill

对比维度 html-i18n i18n-helper
适用场景 书籍、文档站、博客、官网落地页 React/Vue/Angular/Laravel/Symfony/WordPress等源码项目
项目特征 只有.html/.css/图片，无源码、无构建配置 有.js/.jsx/.vue/.php/.py/.java等源码
处理方式 复制HTML文件成多语言目录 把硬编码替换成翻译函数调用
产物结构 en/、ja/、zh-TW/等独立目录 JSON/YAML/PO/XLIFF/PHP数组/Properties
翻译函数 无需翻译函数 t() / __() / trans()等
依赖 Python标准库 Python标准库
SEO友好 ✅ 多语言独立URL ✅ 客户端动态切换

📌 快速选择指南

• 纯静态HTML站点（书籍、文档、博客）→ html-i18n
• 需要在代码里写翻译函数（React、Vue、Laravel等）→ i18n-helper
• 一句话区分：要把HTML文件复制成多语言目录 → html-i18n；要写t()/__()翻译函数 → i18n-helper

安装配置

快速开始国际化

安装方式
# 方式一：用户级（所有项目可用）
cp -r skills/html-i18n ~/.agents/skills/
cp -r skills/i18n-helper ~/.agents/skills/

# 方式二：项目级（仅当前项目可用）
cp -r skills/html-i18n 你的项目/.agents/skills/
cp -r skills/i18n-helper 你的项目/.agents/skills/
html-i18n使用步骤
# 1. 提取翻译源
python skills/html-i18n/scripts/extract.py 你的站点/

# 2. 复制zh-CN.json改名并填译文
# 3. 应用生成各语言目录
python skills/html-i18n/scripts/apply.py 你的站点/ locales/en-US.json 你的站点/en --lang en

# 4. 检查完整性
python skills/html-i18n/scripts/check.py locales/
