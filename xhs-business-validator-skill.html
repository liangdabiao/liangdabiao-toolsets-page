为什么做这个？

验证业务创意不该是开发者的专利

🧠 传统业务验证的痛点

想验证一个商业想法，通常需要写代码爬数据、跑分析脚本、再人工整理结论——门槛高、耗时长，让很多不错的创意还没验证就搁置了。 而市面上又缺乏把"市场反馈"直接搬进对话里的工具。本 Skill 把整个流程封装成一句话触发： 搜索小红书相关笔记与评论 → AI 提取用户痛点与市场信号 → 给出 0-100 评分与可执行的判断， 让任何人都能在 1-15 分钟内拿到一份完整的市场验证报告。

核心功能

一句话触发，从想法到市场验证报告全流程打通

💬

对话内激活

直接在对话中说出业务想法，技能自动触发验证流程，无需写代码、无需跑脚本，开箱即用。

🔎

小红书笔记检索

通过 TikHub API 搜索与你想法相关的笔记与评论，拿到真实用户讨论数据作为验证依据。

🧩

用户痛点分析

用 AI 分析用户到底在抱怨什么、需要什么，提取关键痛点、现有解决方案与潜在市场机会。

📊

0-100 综合评分

基于讨论热度、用户反馈、竞争情况等综合维度给想法打分，明确告诉你值不值得做。

⚡

两种验证模式

快速模式（1-2 分钟，搜 1 页看 5 条评论）适合初步判断；完整模式（5-15 分钟，搜 2 页看 20 条评论）适合认真分析出报告。

📄

HTML 验证报告

每次运行生成完整 HTML 市场验证报告，保存在 reports/ 目录，浏览器双击即可查看，可分享可归档。

🗂️

历史报告回看

一句"看看上次的报告"即可调出最近一次验证结果，附评分与主要问题摘要，方便对比多次创意。

🎨

四色评分等级

80-100 绿（机会很大可冲）/ 60-79 黄（有潜力值得深入）/ 40-59 橙（需再验证别急投）/ 0-39 红（建议换方向），结果一目了然。

核心原理与步骤

1. 触发与模式选择
在对话中说出业务创意，技能自动触发并询问使用快速模式还是完整模式；也可手动加载 /xhs-business-validator。
2. 数据采集
通过 TikHub API 搜索小红书与想法相关的笔记及评论，按模式决定抓取页数与评论条数，拿到一手用户讨论数据。
3. AI 信号提取
用 AI 分析内容，提取用户痛点、现有解决方案与市场机会，作为评分与结论的事实依据。
4. 综合评分与报告
基于讨论热度、用户反馈、竞争情况等综合评分（0-100），给出四色等级判断，并在 reports/ 生成可浏览器打开的 HTML 报告。

安装与配置

Skill 形态，配置好 TikHub 密钥即可开箱即用

1. 获取 Skill

克隆仓库或放置到 skills 目录：

git clone https://github.com/liangdabiao/xhs-business-validator-skill.git
cd xhs-business-validator-skill
2. 文件结构

Skill 目录结构如下：

./skills/xhs-business-validator/
├── SKILL.md   # 技能定义（给 AI 看的）
└── README.md  # 说明文件（给你看的）
3. 配置 TikHub 密钥

技能已配置好 TikHub（https://tikhub.io/）密钥，开箱即用。如需使用自己的密钥，按 SKILL.md 说明配置。

4. 在对话中使用

直接说出需求自动触发，或手动加载：

用户：帮我验证一下在深圳卖陈皮这个想法
AI：  好的！用快速模式还是完整模式？

# 手动加载
/xhs-business-validator 帮我看看在深圳卖陈皮怎么样
5. 查看结果与报告

运行完成后浏览器打开 HTML 报告：

reports/在深圳卖陈皮_20260818_143022.html

常见问题

关于小红书业务创意验证器 Skill 的常见疑问

Q: 这个 Skill 和 xhs-business-idea-validator 是什么关系？
A: xhs-business-idea-validator 是 MCP 架构的全栈 Web 应用；本仓库 xhs-business-validator-skill 是它的 Skill 形态——直接在对话中触发，无需启动 Web 服务，更适合随想随验的场景。
Q: 需要自己申请 TikHub 密钥吗？
A: 技能已配置好 TikHub（https://tikhub.io/）密钥，开箱即用。如需更高配额可自行配置自己的密钥。
Q: 快速模式和完整模式怎么选？
A: 快速模式约 1-2 分钟，搜 1 页看 5 条评论，适合随便看看、初步判断；完整模式约 5-15 分钟，搜 2 页看 20 条评论，适合认真分析、要出报告。
Q: 评分 70 分代表什么？
A: 评分采用四色等级：80-100 🟢 市场机会很大可以冲；60-79 🟡 有一定潜力值得深入；40-59 🟠 需要再验证别急着投钱；0-39 🔴 风险较高建议换个方向。70 分属于"有一定市场潜力"的黄色档。
Q: 生成的 HTML 报告保存在哪？
A: 报告保存在 reports/ 目录，文件名形如「在深圳卖陈皮_20260818_143022.html」，浏览器双击即可打开查看。用"看看上次的报告"可回看最近一次结果。
