为什么选择Mathigon？

获奖平台的互动学习体验

互动教科书：数学不再只是阅读

Mathigon是全球获奖的互动数学教育平台，其核心理念是"教科书不再只是阅读，而是探索"。通过Markdown驱动的互动内容、TypeScript交互元素、虚拟导师系统，让抽象数学变得直观有趣。本fork新增"mathigon textbooks skill"，一行命令即可生成专业STEM课程。

安装与配置

一键启动互动教学平台

前置条件

Node.js 14+、NPM、FFmpeg（用于TTS音频生成）。

1. 克隆项目
git clone https://github.com/liangdabiao/textbooks
cd textbooks
2. 安装依赖
npm install
3. 启动服务
npm start
# → http://localhost:5000

常见问题

Q: 与原版Mathigon有什么区别？
A: 本项目是Mathigon的fork，并新增"mathigon textbooks skill"，支持一行命令基于Markdown生成完整STEM课程。
Q: 适合哪些年龄段？
A: 主要面向12-18岁初高中学生，覆盖代数、几何、微积分、统计、物理等STEM学科。
Q: 是否支持中文？
A: 通过GitLocalize翻译工作流支持多语言，包含中文。TTS音频可通过Google Cloud TTS生成。
