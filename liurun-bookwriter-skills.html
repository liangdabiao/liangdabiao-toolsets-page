两套完整的中文长文写作体系

刘润商业洞察风格

罗振宇启发式风格

自动识别3段式/10点式/32条/5商派结构，验证段落数正确性和编号连续性。

工作流程

从一句话到完整长文

1️⃣

触发Skill

直接对Agent说："用刘润的风格写一篇关于鸿蒙的32条评论"

2️⃣

识别结构

Agent自动识别结构类型，选定SCQA变体，确认选题角度

3️⃣

调研素材

自动调研案例、数据、金句等素材

4️⃣

撰写

遵循写作心法逐段撰写，每写完一段等待用户确认

5️⃣

QC自检

执行12项质量检查，确保文章质量

6️⃣

导出

支持Markdown、PDF格式导出，方便分享和打印

安装配置

快速开始写作

安装方式
# 复制到Agent skills目录
cp -r liurun-bookwriter ~/.claude/skills/
cp -r luozhenyu-bookwriter ~/.claude/skills/

# 或作为本地Skill目录
直接告诉Agent skill所在路径即可
PDF导出依赖
# macOS
brew install pandoc
brew install --cask mactex
brew install --cask font-source-han-serif

# Linux (Ubuntu/Debian)
sudo apt install pandoc texlive-xetex texlive-lang-chinese fonts-noto-cjk

# Windows
winget install --id JohnMacFarlane.Pandoc
winget install --id MiKTeX.MiKTeX
命令行工具
# PDF导出
python scripts/export_pdf.py article.md

# 结构验证
python scripts/validate_structure.py article.md

# 多Agent协作调度
python scripts/agent_scheduler.py --init "32-tiao-hongmeng" --type "32条"
