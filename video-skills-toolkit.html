为什么需要Skill工具包？

把视频制作变成可重复流水线

6种视频风格，一套工具搞定

短视频时代，内容创作者需要应对不同场景：知识科普用谈话头像，深度文章用公众号视频，数学教育用证明动画，童话故事用剪纸风格。本工具包一次性提供6种Skill，覆盖主流视频风格，让你的视频创作从"重新造轮子"变成"开箱即用"。

安装与配置

一行命令创建第一个视频

前置条件

Node.js 16+、Python 3.8+、FFmpeg、Bun（可选）。

1. 创建项目
python3 skills/talking-head-remotion/scripts/scaffold_talking_head_remotion_project.py \
  --project-dir ./demo --title "Demo"
2. 安装依赖
cd demo
npm install
3. 渲染输出
npm run still   # 单帧预览
npm run render  # 完整视频

常见问题

Q: 6个Skill可以单独使用吗？
A: 可以。每个Skill独立设计，可根据需求单独安装使用，也可整套安装覆盖所有视频风格。
Q: 共享了哪些素材？
A: 共享9款字体+7款音效库，跨Skill统一调用，保证视频风格一致性。
Q: audio-to-subtitles支持哪些格式？
A: 支持输出SRT、VTT、JSON三种字幕格式，适配主流视频平台与播放器。
