为什么做这个？

让拼豆创作从「手动着色、对色号、估数量」里解放出来

🧵 传统拼豆创作的痛点

传统拼豆软件颜色识别不准、灰色毛边多、无法自适应合并同色系、手动着色困难、无法精准选色， 更要命的是不给你采购清单——不知道要买哪些色号、各买多少颗。 本 Skill 用 Agent Skill 形态封装了「图片→真实拼豆色号→图纸+购物清单」的完整流程， 内置 205 色 × 5 品牌色号对照表开箱即用，AI 优化还能把原图改成 chibi 画风 + 白底 + 像素风再出图， 一句话触发，几秒出图、零成本。

核心功能

从图片到可照拼图纸、可照买清单的全流程支持

🖼️

图片转拼豆图纸

自动把图片缩小成 N×N 网格，每格匹配到能买到的真实拼豆颜色，生成标好色号的图纸 PNG。也支持 JSON 输入（{gridSize, pixelData}）直接出图。

📋

购物清单导出

图纸底部自带色号统计（色块 + 色号 + 颗数 + 总计），还能用 --csv 导出 Excel 可直接打开的购物清单 CSV。

🎨

AI 优化出图

一句话触发 AI 把原图改成 chibi 画风 + 白底 + 像素风后重新出图，按优先级自动选 codex image_gen 或 apiz 图像编辑，基于原图参考图改绘。

🌈

5 大品牌色号

内置 MARD / COCO / 漫漫 / 盼盼 / 咪小窝共 205 色对照表，开箱即用。同一颜色在不同品牌色号不同，按 --system 切换即可。

🎯

颜色收敛合并

--max-colors 限制颜色数，照片直出上百种颜色时自动保留用量最多的若干种、其余合并到最接近的颜色，主体轮廓不受影响。

⬜

背景留空省豆

--blank-white 让白色背景留空不买白豆，省一半豆子。阈值可调（--white-threshold），透明 PNG 自动按白底处理。

🔢

规范图纸排版

深色标题栏 + 作品名水印、行列编号（每 10 格及首尾标注）、每 10 格加深网格线、深浅格自适应黑白字保证看得清。

🤖

核心算法原理

1. 初始颜色映射
把每格像素匹配到色板里最近的真实色号。默认 --match rgb 用欧氏距离，--match lab 更接近人眼判断，觉得颜色怪可切换。
2. 颜色收敛合并
--max-colors 限制颜色数，保留用量最多的 N 种颜色，其余合并到最接近的颜色，控制颜色数量让豆子好买。
3. 背景留空处理
--blank-white 时白色背景格标记为留空不买白豆；透明 PNG 自动按白底处理；阈值可调放宽判定。
4. 图纸排版与统计
标题栏 + 行列坐标 + 每 10 格加深线 + 深浅格自适应黑白字，底部色号统计（色块 / 号 / 颗数 / 总计），可导出 CSV 清单。

安装与配置

作为 Agent Skill 安装，一句话触发拼豆图纸生成

1. 克隆 / 安装 Skill

把 skill 放到 .agents/skills 目录：

git clone https://github.com/liangdabiao/perler-beads-skill.git
# 放到 .agents/skills/pindou-pattern 目录
2. 安装依赖

首次使用只需安装唯一依赖 sharp（图像渲染库）：

cd .agents/skills/pindou-pattern
npm install
3. 直接出图（免费，几秒）

推荐 48×48 网格 + 限制 16 色，细节和难度均衡：

node .agents/skills/pindou-pattern/scripts/generate.js 你的图片.png \
  --size 48 --system 盼盼 --max-colors 16 --title 作品名
4. AI 优化后再出图

先 AI 改画风，再白底留空 + 收敛颜色：

node .agents/skills/pindou-pattern/scripts/optimize.js 你的图片.png
node .agents/skills/pindou-pattern/scripts/generate.js 你的图片_optimized.jpg \
  --size 48 --system 盼盼 --blank-white --max-colors 16
5. 对 AI 助手说一句话（推荐）

在 Claude Code / codex 等 Agent 中直接自然语言触发：

把 test.png 做成 48×48 的拼豆图纸，用盼盼色号，并导出购物清单

常见问题

关于拼豆图纸生成器 Skill 的常见疑问

Q: 为什么我的照片出图后有一百多种颜色？
A: 照片颜色过渡太多。加 --max-colors 16，系统会保留用量最多的 16 种颜色，其余合并到最接近的颜色，主体轮廓不受影响。推荐 12~24 种才好买豆。
Q: 背景明明是白的，怎么还要买白豆？
A: 两种情况：① 没加 --blank-white，白色背景会被匹配成最接近的浅色豆（色板里没有纯白，纯白只表示留空）；② 加了但 AI 生成的「白底」不是纯白（如 RGB 245,251,251），默认阈值 240 接不住就用 --white-threshold 230 放宽判定。
Q: 48×48 细节不够、主体太糊怎么办？
A: 升网格：--size 64 或 --size 100。注意豆数是平方增长：48²=2304 颗，100²=10000 颗，越精细拼得越久。
Q: 图纸里的色号在店里对不上？
A: 确认 --system 选对了品牌。同一颜色在不同品牌色号完全不同（同一个红：MARD 是 F02，盼盼是 31）。看豆子包装色号格式：字母+数字是 MARD/COCO/漫漫，纯数字是盼盼/咪小窝。
Q: AI 优化和直接出图有什么区别？
A: 直接出图免费几秒；AI 优化会先把原图改成 chibi 画风 + 白底 + 像素风再出图，适合直出颜色太乱、细节糊、或想要更卡通可爱效果的场景。AI 优化必须基于原图参考图改绘，按优先级自动选 codex image_gen 或 apiz。
