📚 语言学习的痛点

传统语言学习存在诸多问题：生词脱离上下文，记忆不牢固；YouTube字幕、网页文章、PDF等优质内容来源分散，难以统一管理； 生词筛选需要手动逐个查找释义，效率低下；缺乏发音示范，难以掌握正确读音；学过的词汇缺少系统沉淀，复习迁移困难。 捕获生词 SeekWord 通过 AI 自动捕获生词并生成学习卡片，借助真实上下文强化记忆，让 Contextual learning 事半功倍。

核心功能

从多来源捕获到智能制卡，全流程语言学习支持

📺

YouTube字幕提取

多层保障字幕提取：pot优先通道拦截播放器真实请求（借鉴read-frog）、页面InnerTube接口、无登录多客户端兜底，自动绕过PO Token签名拦截

📰

多来源内容捕获

支持YouTube字幕、任意网页文章、在线PDF文档、划词选中文字、手动粘贴文本，五种内容来源统一管理

📄

PDF正文提取

内置pdf.js本地解析（免费离线隐私好），扫描版/无文本层自动切换Firecrawl在线兜底，支持前200页处理

🤖

AI智能筛选制卡

AI对生词初筛只挑真正值得学的，用户在面板微调选择，自动生成含音标、词性、释义、例句、笔记的学习卡片

🔊

Edge TTS朗读

默认微软神经语音（美音AriaNeural/英音SoniaNeural），HMAC签名换取临时令牌合成MP3，令牌缓存10分钟自动刷新，失败回退浏览器语音

📖

单词本管理

记录所有学过的内容与单词，按来源过滤（视频/文章/划词/手动），便于课后复习与导出，集中沉淀学习成果

🌍

多语言释义

支持简中/繁中/英/西/日/韩/法/俄/德等9种释义语言，各国学习者都能学各国语言

🔌

多LLM服务商

支持Gemini、OpenAI、Claude、OpenRouter、OpenAI兼容接口（DeepSeek/通义/Kimi/智谱），API Key仅本地保存不上传

核心原理与步骤

1. 多来源捕获
从YouTube字幕、网页文章、PDF、划词、粘贴文本统一获取内容，字幕提取采用多路径降级保障成功率
2. AI智能筛选
大模型对生词做初筛，只挑真正值得学的词汇与表达，用户在面板中微调最终选择
3. 学习卡片生成
自动生成含音标、词性、释义、例句、笔记的卡片，点击喇叭朗读发音，支持键盘左右切换单词卡
4. 上下文强化
预习完成后回到原文阅读/观看，例句来自你要学的原文，强上下文让记忆更牢固

安装与配置

简单几步，开始捕获生词学习之旅

1. 克隆项目

获取项目代码：

git clone https://github.com/liangdabiao/SeekWord.git
cd SeekWord
2. 加载已解压扩展（推荐）

Chrome：地址栏输入 chrome://extensions → 右上角开启「开发者模式」→ 点击「加载已解压的扩展程序」→ 选择项目根目录

Edge：edge://extensions → 左下角开启「开发人员模式」→ 点击「加载解压缩的扩展」→ 选择项目根目录
3. 手动安装 .crx（备选）

将项目根目录的 CaptiPrep-main.crx 拖入扩展页面：

chrome://extensions → 开发者模式 → 拖入 CaptiPrep-main.crx → 添加扩展程序
# 若报 CRX_REQUIRED_PROOF_MISSING，改用「加载已解压」方式
4. 配置大模型（选项页）

右键扩展图标 → 选项，配置 API Key、Base URL 与模型：

推荐：筛选模型 gemini-3.1-flash-lite，制卡模型 gemini-3.5-flash
支持：Gemini / OpenAI / Claude / OpenRouter / OpenAI Compatible（DeepSeek、通义、Kimi、智谱）
API Key 仅保存在本地浏览器，不会上传
5. 开始使用

打开任意英文内容页面，点击扩展图标或右键菜单：

YouTube视频 / 网页文章 / 在线PDF / 划词 / 粘贴文本
→ 提取内容 → 选择要学的词 → 生成卡片 → 学习
点击键盘左右切换单词卡，空格收藏单词

常见问题

关于捕获生词 SeekWord 的常见疑问

Q: AI功能需要付费吗？
A: 需要配置大模型 API Key（如 Gemini、OpenAI、Claude 等）。推荐使用 Gemini，筛选用 gemini-3.1-flash-lite，制卡用 gemini-3.5-flash，速度与效果均衡。
Q: 支持哪些内容来源？
A: 支持五种来源：YouTube字幕、任意网页文章、在线PDF文档、网页划词选中文字、手动粘贴文本，全部统一在浮层面板管理。
Q: YouTube字幕提取失败怎么办？
A: 插件采用多路径降级：pot优先通道（拦截播放器真实请求）→ 页面ytInitialPlayerResponse → 页面InnerTube → 后台无登录多客户端兜底。打开控制台执行 window.CC_DEBUG = true 可查看详细诊断日志。
Q: 朗读发音怎么实现？
A: 默认使用 Edge TTS 微软神经语音（美音AriaNeural/英音SoniaNeural），通过HMAC签名换取临时令牌合成MP3音频，免费无需API key。令牌缓存10分钟自动刷新，失败自动回退浏览器系统语音。
Q: API Key 安全吗？
A: API Key 仅保存在本地浏览器，不会上传。配置在选项页完成，支持五种服务商切换，填写完整Base URL后可点击「显示大模型列表」自动拉取可用模型名。
