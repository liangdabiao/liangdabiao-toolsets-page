🚀 快速开始

环境要求

Python版本: 3.12+
依赖管理: Poetry (推荐) / UV
AI模型: Ollama (本地) / OpenAI GPT

安装步骤

# 1. 克隆项目 git clone https://github.com/liangdabiao/easy_investment_Agent_crewai cd easy_investment_Agent_crewai # 2. 安装依赖 (推荐使用 Poetry) poetry install --no-root # 3. 配置环境 cp .env.example .env # 编辑 .env 文件配置必要参数 # 4. 运行分析 (默认分析腾讯控股) poetry run python src/a_stock_analysis/main.py # 或使用安装的脚本 poetry run a_stock_analysis

支持 UV 安装: uv sync 一键安装所有依赖

📊 支持的股票代码格式

市场类型 代码格式 示例 说明
上交所A股 股票代码.SH 600519.SH 贵州茅台
深交所A股 股票代码.SZ 000001.SZ 平安银行
港股 股票代码.HK 00700.HK 腾讯控股

🔧 自定义配置示例

# 分析贵州茅台 inputs = { 'company_name': '贵州茅台', 'stock_code': '600519.SH', 'market': 'SH' } # 切换AI模型 (在 crew.py 中) from langchain.llms import Ollama llm = Ollama(model="llama3.1") # 或使用 OpenAI GPT from langchain.chat_models import ChatOpenAI llm = ChatOpenAI(model='gpt-4')

⚠️ 风险提示

本系统仅供学习研究使用，不构成投资建议。A股市场风险较高，投资需谨慎。建议结合多种分析方法做出投资决策，过往业绩不代表未来表现。
