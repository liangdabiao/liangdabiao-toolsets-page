安装与使用

快速开始你的周末旅行规划

1. 克隆项目
git clone https://github.com/liangdabiao/weekend-city-trip.git
2. 安装依赖
npm install
3. 配置API密钥
export OPENAI_API_KEY=your-api-key
4. 启动应用
npm run dev

常见问题

关于 Weekend City Trip 的常见疑问

Q: 支持哪些城市？
A: 目前支持国内大部分热门旅游城市，包括北京、上海、广州、深圳、杭州、成都、重庆等。
Q: 是否需要付费API？
A: 需要配置大语言模型API密钥（如OpenAI），部分功能可能需要Google Maps等第三方API。
Q: 如何自定义旅行偏好？
A: 可以设置旅行风格（休闲/探险/文化）、预算范围、出行人数、交通方式等偏好参数。
