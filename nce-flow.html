安装与使用

快速开始

1. 获取完整代码
git clone https://github.com/liangdabiao/NCE-Flow.git
# 或从 Releases 下载含完整音频的压缩包
2. 本地运行
python3 -m http.server 8080
# 访问 http://localhost:8080
3. 部署上线
直接部署到 GitHub Pages / EdgeOne 等静态平台即可
