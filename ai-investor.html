安装与使用

快速开始智能投资分析

1. 克隆项目
git clone https://github.com/liangdabiao/ai-investor.git
2. 安装依赖
pip install -r requirements.txt
3. 配置API密钥
export OPENAI_API_KEY=your-api-key
4. 运行应用
python main.py

常见问题

关于 AI Investor 的常见疑问

Q: AI Investor 能保证投资收益吗？
A: AI Investor 提供投资分析和建议，但投资有风险，决策最终由投资者自行做出。我们不保证任何投资收益。
Q: 支持哪些市场？
A: 目前主要支持A股、美股、港股市场的股票分析，未来将扩展到更多市场和投资品种。
Q: 需要哪些API密钥？
A: 需要配置大语言模型API密钥（如OpenAI、Anthropic等），以及可选的股票数据API密钥。
